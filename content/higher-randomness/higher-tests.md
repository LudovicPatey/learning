The previous two lessons described $\Pi^1_1$ and $\Delta^1_1$ classes and their measure. This lesson defines the first two notions of higher randomness. Martin-Löf himself proposed in 1970 to call random the sequences avoiding every null class that is effectively Borel, the $\Delta^1_1$ classes. Hjorth and Nies (2007) defined the higher analogue of Martin-Löf tests, in which c.e. sets of strings are replaced by $\Pi^1_1$ sets. The first notion is the simpler to state, the second has the better structure: it has a universal test, built as in the classical case by trimming the components of all candidate tests, the stages of the enumeration now being computable ordinals. The analogy between $\Pi^1_1$ sets and c.e. sets, developed in the course on effective descriptive set theory, is the main tool.

## Δ¹₁-randomness

Every sequence $X$ belongs to a null class, the singleton $\{ X \}$, so a notion of randomness must restrict the null classes it considers. Martin-Löf randomness keeps the effectively $\Pi^0_2$ ones; the first higher notion keeps the hyperarithmetic ones.

:::definition{#def-delta11-random}
A sequence is **$\Delta^1_1$-random** if it belongs to no null $\Delta^1_1$ class.
:::

:::example{#ex-delta11-null}
Let $A$ be hyperarithmetic. By :ref{#ex-delta11-classes}, the following null classes are $\Delta^1_1$: the singleton $\{ A \}$; the class $\{ Y : Y \leq_T A \}$, which is countable; the class captured by a Martin-Löf test relative to $A$, for instance relative to $\emptyset^{(n)}$ or to $\emptyset^{(\omega)}$. A null class that is not $\Delta^1_1$ is the class of well-founded relations (:ref{#ex-measure-pi11}); the lesson on $\Pi^1_1$-randomness shows that it is nevertheless avoided by every $\Delta^1_1$-random sequence, while some other null $\Pi^1_1$ classes are not.
:::

The first two examples give the basic properties of the notion.

:::proposition{#prop-delta11-arith}
Every $\Delta^1_1$-random sequence is $n$-random for every $n$, and is not hyperarithmetic.
:::

:::proof{of=prop-delta11-arith}
A Martin-Löf test relative to $\emptyset^{(n-1)}$ captures a null class $\bigcap_k \mathcal U_k$ with $\mathcal U_k$ uniformly $\Sigma^0_1(\emptyset^{(n-1)})$; it is arithmetic, hence $\Delta^1_1$. If $X$ is hyperarithmetic, the singleton $\{ X \}$ is a null $\Delta^1_1$ class containing $X$ (:ref{#ex-delta11-classes} (1)).
:::

::::exercise{difficulty=1}
Show that the class of $\Delta^1_1$-random sequences has measure $1$.

:::solution
A $\Delta^1_1$ class is defined by a pair of formulas, so there are countably many $\Delta^1_1$ classes. The sequences that are not $\Delta^1_1$-random form the union of the null ones, a countable union of null classes, hence a null class.
:::
::::

## Higher Martin-Löf tests

The higher analogue of a $\Sigma^0_1$ class is an open class generated by a $\Pi^1_1$ set of strings. For a set $W$ of strings, $[W]$ denotes the open class of sequences extending some member of $W$.

:::proposition{#prop-pi11-open}
A class $\mathcal U$ is open and $\Pi^1_1$ if and only if $\mathcal U = [W]$ for some $\Pi^1_1$ set of strings $W$.
:::

:::proof{of=prop-pi11-open}
If $W$ is $\Pi^1_1$, then $X \in [W]$ if and only if $\exists n\ X \uh n \in W$; a number quantifier in front of a $\Pi^1_1$ formula gives a $\Pi^1_1$ formula. Conversely, if $\mathcal U$ is open and $\Pi^1_1$, let $W = \{ \sigma : \forall X\ (\sigma \prec X \rightarrow X \in \mathcal U) \}$, which is $\Pi^1_1$. Every $X \in \mathcal U$ has a prefix $\sigma$ with $[\sigma] \subseteq \mathcal U$, since $\mathcal U$ is open; so $\mathcal U = [W]$.
:::

:::definition[Hjorth, Nies]{#def-higher-ml}
A **higher Martin-Löf test** is a sequence of classes $\mathcal U_n = [W_n]$ such that the set $\{ (n, \sigma) : \sigma \in W_n \}$ is $\Pi^1_1$ and $\lambda(\mathcal U_n) \leq 2^{-n}$ for every $n$. A sequence is **$\Pi^1_1$-Martin-Löf random** if it belongs to no class $\bigcap_n \mathcal U_n$ of such a test.
:::

Every Martin-Löf test is a higher Martin-Löf test, since c.e. sets are $\Pi^1_1$; so $\Pi^1_1$-Martin-Löf random sequences are Martin-Löf random.

:::example{#ex-higher-ml-tests}
1. If $A$ is hyperarithmetic, the sets $W_n = \{ A \uh n \}$ form a higher Martin-Löf test, since the relation $\sigma = A \uh |\sigma|$ is $\Delta^1_1$; it captures $A$. More generally, a Martin-Löf test relative to a hyperarithmetic set is a higher Martin-Löf test, since a relation c.e. in a $\Delta^1_1$ set is $\Delta^1_1$ (:ref{#ex-delta11-classes} (2)).
2. The uniformity in $n$ cannot be dropped. For any sequence $X$, each class $[X \uh n]$ is clopen, generated by a single string, hence $\Pi^1_1$, of measure $2^{-n}$; the intersection of these classes is $\{ X \}$. Without the requirement that $\{ (n, \sigma) : \sigma \in W_n \}$ be $\Pi^1_1$ as a whole, no sequence would be random.
:::

:::proposition{#prop-higher-ml-delta11}
Every $\Pi^1_1$-Martin-Löf random sequence is $\Delta^1_1$-random.
:::

:::proof{of=prop-higher-ml-delta11}
Let $\mathcal D$ be a null $\Delta^1_1$ class. By :ref{#fact-higher-borel} (2), there are a hyperarithmetic set $A$ and sets of strings $W_k$, uniformly c.e. in $A$, with $\mathcal D \subseteq [W_k]$ and $\lambda([W_k]) \leq \lambda(\mathcal D) + 2^{-k} = 2^{-k}$. The relation $\sigma \in W_k$ is $\Sigma^0_1(A)$, hence $\Delta^1_1$, in particular $\Pi^1_1$ (:ref{#ex-delta11-classes} (2)). So $([W_k])$ is a higher Martin-Löf test, and it captures every member of $\mathcal D$.
:::

The test built in the proof is in fact a Martin-Löf test relative to a hyperarithmetic set; the exercise at the end of the lesson draws the consequence. The converse of the proposition fails: some $\Delta^1_1$-random sequence is not $\Pi^1_1$-Martin-Löf random. This is due to Hjorth and Nies. Monin and Patey give a direct construction, a $\Pi^1_1$ construction along the stages of an enumeration of the $\Delta^1_1$ classes of measure $1$; Nies derives it from a $\Delta^1_1$-random sequence of slowly growing initial segment complexity (Theorem 9.3.4 and Corollary 9.3.5). We admit it.

:::quiz[higher tests and Δ¹₁ classes]
In the proof of :ref{#prop-higher-ml-delta11}, why is the approximation of :ref{#fact-higher-borel} (2) needed, rather than the class $\mathcal D$ itself?

- [x] Because the components of a higher Martin-Löf test must be open classes generated by a $\Pi^1_1$ set of strings, and a $\Delta^1_1$ class is not open in general; the approximation provides open classes of small measure containing it.
- [ ] Because $\mathcal D$ is not measurable.

  Every $\Delta^1_1$ class is Borel, by :ref{#lem-stages-borel} and :ref{#cor-delta11-stage}.
- [ ] Because $\mathcal D$ is not $\Pi^1_1$.

  It is $\Pi^1_1$, being $\Delta^1_1$; the problem is that it is not open.
:::

## A universal higher test

As in the classical case, there is a universal test (:ref{#thm-universal-test}), and it is built by the same technique, **trimming**. One lists all candidate tests, enumerates each candidate component, and keeps a string only as long as the strings kept so far have measure at most $2^{-n}$; genuine tests are left unchanged, and the shifted union of the trimmed components is a test. In the classical case the enumeration proceeds in steps $0, 1, 2, \dots$, and the measure enumerated up to a step is a rational. In the higher case the candidates are $\Pi^1_1$ sets of strings, enumerated along the computable ordinals, and there are limit stages. What makes the trimming work is that "the measure of the strings enumerated up to the stage of $\sigma$" is still a $\Pi^1_1$ condition on $\sigma$, by stage comparison (:ref{#thm-stage-comparison}).

Let $U \subseteq \nat$ be the $\Pi^1_1$ set of :ref{#prop-pi11-not-sigma11}, whose sections include all $\Pi^1_1$ sets. Coding triples by numbers, let $V$ be the $\Pi^1_1$ set of triples $(e, n, \sigma)$ such that $\langle e, \langle n, \sigma \rangle \rangle \in U$. Then every $\Pi^1_1$ set of pairs $(n, \sigma)$ is $\{ (n, \sigma) : (e, n, \sigma) \in V \}$ for some $e$. Fix stages $\rho$ for $V$, as in :ref{#thm-stage-comparison}, given by uniformly computable trees. Write $V_{e, n} = \{ \sigma : (e, n, \sigma) \in V \}$.

:::theorem[Hjorth, Nies]{#thm-higher-universal}
There is a universal higher Martin-Löf test: a test $(\mathcal U_n)$ such that $\bigcap_n \mathcal U_n$ contains $\bigcap_n \mathcal V_n$ for every higher Martin-Löf test $(\mathcal V_n)$.
:::

:::proof{of=thm-higher-universal}
For $e$, $n$ and $\sigma$, write $\rho(e, n, \sigma)$ for the stage of the triple. Let $\widehat V_{e, n}$ be the set of strings $\sigma \in V_{e, n}$ such that, for every finite set $F$ of strings,
$$
\big( \forall \tau \in F\ \ \rho(e, n, \tau) \leq \rho(e, n, \sigma) \big) \rightarrow \lambda([F]) \leq 2^{-n}.
$$
By :ref{#lem-rank-comparison}, the hypothesis of the implication is $\Sigma^1_1$, so the implication is $\Pi^1_1$; the quantifier over finite sets is a number quantifier, and $\sigma \in V_{e, n}$ is $\Pi^1_1$. So $\widehat V_{e, n}$ is $\Pi^1_1$, uniformly in $e$ and $n$.

*Measure.* Let $F$ be a non-empty finite subset of $\widehat V_{e, n}$, and $\sigma \in F$ with the largest stage. All $\tau \in F$ satisfy $\rho(e, n, \tau) \leq \rho(e, n, \sigma)$, so $\lambda([F]) \leq 2^{-n}$ since $\sigma \in \widehat V_{e, n}$. The open class $[\widehat V_{e, n}]$ is the increasing union of the classes $[F]$ for finite $F \subseteq \widehat V_{e, n}$, so its measure is at most $2^{-n}$.

*No change for tests.* If $\lambda([V_{e, n}]) \leq 2^{-n}$, then every finite $F \subseteq V_{e, n}$ has $\lambda([F]) \leq 2^{-n}$, and in particular those whose members have stages at most $\rho(e, n, \sigma)$; so $\widehat V_{e, n} = V_{e, n}$.

Let $\mathcal U_n = \bigcup_e [\widehat V_{e, n + e + 1}]$. It is generated by the set of strings $\{ \sigma : \exists e\ \sigma \in \widehat V_{e, n+e+1} \}$, which is $\Pi^1_1$ uniformly in $n$, and $\lambda(\mathcal U_n) \leq \sum_e 2^{-n-e-1} = 2^{-n}$. If $(\mathcal V_n)$ is a higher Martin-Löf test, generated by $V_{e, n}$ for some $e$, then $\widehat V_{e, m} = V_{e, m}$ for every $m$, and $\bigcap_n \mathcal V_n \subseteq \bigcap_n \mathcal V_{n+e+1} \subseteq \bigcap_n \mathcal U_n$.
:::

:::quiz[the universal test]
In the proof of :ref{#thm-higher-universal}, why does the trimming condition quantify over the finite sets of strings whose stages are at most that of $\sigma$?

- [x] Because the condition must bound the measure of the part of $V_{e, n}$ enumerated up to the stage of $\sigma$, and be $\Pi^1_1$: the measure of an open class is the supremum of the measures of the classes $[F]$ for its finite subsets $F$, and a quantifier over finite sets is a number quantifier.
- [ ] Quantifying over all finite subsets of $V_{e, n}$ would work as well.

  The condition "$F \subseteq V_{e, n} \rightarrow \lambda([F]) \leq 2^{-n}$" has a $\Pi^1_1$ hypothesis, so it is only $\Sigma^1_1$; and it would keep all of $V_{e, n}$ or nothing, according to the measure of $[V_{e, n}]$.
- [ ] Because the stages are natural numbers.

  The stages are computable ordinals; a stage may have infinitely many predecessors.

---

Why is the hypothesis of the implication required to be $\Sigma^1_1$?

- [x] Because it appears on the left of an implication: its negation must be $\Pi^1_1$ for the whole condition to be $\Pi^1_1$, and the comparison of stages through strictly monotone maps provides a $\Sigma^1_1$ definition.
- [ ] Because $\Sigma^1_1$ relations are decidable.

  They are not; the point is the complexity of the negation.
- [ ] Because $\lambda([F]) \leq 2^{-n}$ is $\Sigma^1_1$.

  For a finite set $F$, this is a computable condition.
:::

:::corollary{#cor-higher-mlr-class}
The class of $\Pi^1_1$-Martin-Löf random sequences is $\Sigma^1_1$ and has measure $1$. It contains a $\Sigma^1_1$ class of positive measure, and therefore a member computable in $\mathcal O$.
:::

:::proof{of=cor-higher-mlr-class}
Its complement is $\bigcap_n \mathcal U_n$ for the universal test, an intersection of uniformly $\Pi^1_1$ classes, hence $\Pi^1_1$, of measure $0$. The complement of $\mathcal U_1$ is $\Sigma^1_1$, of measure at least $\frac12$, and contained in the class of random sequences. By the Kleene basis theorem (:ref{#thm-kleene-basis}), it has a member computable in $\mathcal O$.
:::

## Exercises

::::exercise{difficulty=2}
Show that a sequence is $\Delta^1_1$-random if and only if it is Martin-Löf random relative to every hyperarithmetic set. Deduce again that $\Pi^1_1$-Martin-Löf randomness implies Martin-Löf randomness relative to every hyperarithmetic set.

:::solution
If $X$ is $\Delta^1_1$-random and $A$ is hyperarithmetic, the class captured by a Martin-Löf test relative to $A$ is a null $\Delta^1_1$ class (:ref{#ex-delta11-null}), so $X$ passes the test. Conversely, let $\mathcal D$ be a null $\Delta^1_1$ class. By :ref{#fact-higher-borel} (2), there are a hyperarithmetic $A$ and sets $W_k$, uniformly c.e. in $A$, with $\mathcal D \subseteq [W_k]$ and $\lambda([W_k]) \leq 2^{-k}$: a Martin-Löf test relative to $A$ that captures every member of $\mathcal D$. A sequence that is Martin-Löf random relative to $A$ therefore avoids $\mathcal D$. The second statement follows from the first and :ref{#prop-higher-ml-delta11}. So $\Delta^1_1$-randomness is the hyperarithmetic analogue of arithmetic randomness: the intersection of Martin-Löf randomness relative to all the H-sets $H_a$, $a \in \mathcal O$, while $n$-randomness for every $n$ is the intersection over the finite jumps.
:::
::::

## Notes and references

$\Delta^1_1$-randomness was proposed by Martin-Löf (1970); Sacks's book studies it in Chapter IV. Hjorth and Nies (2007) introduced $\Pi^1_1$-Martin-Löf randomness, higher prefix-free complexity and the higher analogue of Schnorr's theorem, and separated the notion from $\Delta^1_1$-randomness. They obtain the universal test from complexity: the classes generated by the strings $x$ with higher prefix-free complexity at most $|x| - b$ form a higher Martin-Löf test (Nies, Proposition 9.2.8), which is universal by the higher Schnorr theorem. The direct construction by trimming given here follows the classical proof of :ref{#thm-universal-test}. The characterization of $\Delta^1_1$-randomness by Martin-Löf randomness relative to hyperarithmetic sets appears in the hint to Nies's Exercise 9.3.13, where it is derived from results of Sacks. Nies (Chapter 9) and Monin and Patey (chapter *Higher randomness*) present this material; Chong and Yu's monograph develops higher randomness systematically.

- P. Martin-Löf, *On the notion of randomness*, in Intuitionism and Proof Theory, North-Holland, 1970, 73–78.
- G. Hjorth and A. Nies, *Randomness via effective descriptive set theory*, Journal of the London Mathematical Society 75 (2007), 495–508.
- C. T. Chong and L. Yu, *Recursion Theory: Computational Aspects of Definability*, De Gruyter, 2015.
- G. E. Sacks, *Higher Recursion Theory*, Springer, 1990, Chapter IV.
- A. Nies, *Computability and Randomness*, Oxford University Press, 2009, Sections 9.2 and 9.3.
