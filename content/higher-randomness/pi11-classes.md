Martin-Löf randomness uses null classes that are effectively $\Pi^0_2$: intersections of uniformly $\Sigma^0_1$ classes. Replacing computability by hyperarithmetic definability gives the notions of **higher randomness**, in which the tests are null $\Delta^1_1$ or $\Pi^1_1$ classes, or intersections of open classes generated by $\Pi^1_1$ sets of strings. Before these notions can be defined, two questions must be answered. A $\Pi^1_1$ class need not be Borel, so it is not clear that it has a measure. And when it has one, a test is only useful if the condition "the measure is small" is itself definable at the right level. Both questions, answered in the next lesson, rest on the structure of $\Pi^1_1$ classes described in this one.

The structure is the picture developed for $\Pi^1_1$ sets of numbers in the course on effective descriptive set theory. A $\Pi^1_1$ set is enumerated along the computable ordinals: an element enters at the stage given by the rank of a computable tree (:ref{#def-pi11-stage}). A $\Pi^1_1$ class is enumerated in the same way, a sequence $Y$ entering at the rank of a $Y$-computable tree. There is one new feature. The ranks of $Y$-computable trees are bounded by $\omega_1^Y$, not by $\omega_1^{\mathrm{CK}}$, so the stages of a $\Pi^1_1$ class may range over all countable ordinals. This lesson shows that a sequence $Y$ enters a $\Pi^1_1$ class at a stage below $\omega_1^Y$, that the stages below $\omega_1^{\mathrm{CK}}$ are $\Delta^1_1$, and that every $\Delta^1_1$ class is such a stage.

## Stages of a Π¹₁ class

A class $\mathcal A \subseteq \cs$ is **$\Pi^1_1$** if it is defined by a formula $\forall Z\, \varphi(Y, Z)$ with $\varphi$ arithmetic, possibly with number parameters; it is **$\Sigma^1_1$** if its complement is $\Pi^1_1$ (:ref{#def-sigma11-class}), and **$\Delta^1_1$** if it is both. The same definitions apply to relations between numbers and sequences. The **Church–Kleene ordinal relative to $Y$**, $\omega_1^Y$, is the least ordinal that is not the type of a $Y$-computable well-ordering; $\omega_1^Y \geq \omega_1^{\mathrm{CK}}$ for every $Y$.

The proof of the normal form theorem (:ref{#thm-pi11-normal-form}) relativizes, uniformly in the set parameter. For every $\Pi^1_1$ class $\mathcal A$ there is a Turing functional that maps every $Y$ to a tree $T^Y$ containing the empty sequence, such that $Y \in \mathcal A$ if and only if $T^Y$ is well-founded. To have a uniform list, write $T^Y_p$ for the tree whose characteristic function is $\Phi^Y_p$, when $\Phi^Y_p$ is total, $\{0, 1\}$-valued, and the characteristic function of a tree containing the empty sequence; this condition on $p$ and $Y$ is arithmetic. We use the notation $\rho(T)$ of :ref{#lem-rank-comparison}: the rank of $T$ if $T$ is well-founded, and $\infty$ otherwise.

:::definition{#def-class-stages}
For a number $p$, let $\mathcal A^p$ be the class of $Y$ such that $T^Y_p$ is defined and well-founded. For an ordinal $\alpha$, the **stage** $\alpha$ of $\mathcal A^p$ is
$$
\mathcal A^p_\alpha = \{ Y : T^Y_p \text{ is defined and } \rho(T^Y_p) < \alpha \}.
$$
For $Y \in \mathcal A^p$, the ordinal $\rho(T^Y_p)$ is the **stage at which $Y$ enters** $\mathcal A^p$.
:::

The classes $\mathcal A^p$ are $\Pi^1_1$, uniformly in $p$, and by the relativized normal form every $\Pi^1_1$ class is $\mathcal A^p$ for some $p$. The stages $\mathcal A^p_\alpha$ increase with $\alpha$. A well-founded tree on $\nat$ is countable, so its rank is a countable ordinal, and $\mathcal A^p$ is the union of its stages $\mathcal A^p_\alpha$ for $\alpha < \omega_1$, the first uncountable ordinal. The stages depend on the chosen index $p$, not only on the class; this is harmless, since the results below hold for every index.

:::example{#ex-class-stages}
1. *Open classes.* Let $W$ be a c.e. set of binary strings with a computable enumeration $(W_s)$, $W_0 = \emptyset$. Let $T^Y$ be the set of sequences $\sigma \in \nat^{<\nat}$ such that no prefix $Y \uh m$ with $m \leq |\sigma|$ belongs to $W_{|\sigma|}$. It is a $Y$-computable tree. If $s$ is the least stage at which some prefix $Y \uh m$ with $m \leq s$ belongs to $W_s$, then $T^Y$ consists of the sequences of length less than $s$, and has rank $s - 1$; if there is no such $s$, then $T^Y$ is ill-founded. So the class is the open class $[W]$, and all its members enter at finite stages, as in :ref{#ex-ce-stages}.
2. *Well-founded relations.* Let $T^Y$ be the tree of finite sequences $x_0, x_1, \dots, x_k$ such that $\langle x_{i+1}, x_i \rangle \in Y$ for every $i < k$: the descending sequences of the binary relation coded by $Y$. The class is the class of $Y$ coding a well-founded relation. When $Y$ codes a non-empty well-ordering $L$, the tree differs from the tree $D_L$ of :ref{#prop-descending-tree} only by the leaves $\langle x \rangle$ for $x$ outside the field of $L$, so it has the same rank $|L|$. Every countable ordinal is the type of a well-ordering of a subset of $\nat$, so the members of this class enter at all countable stages: the stages of a $\Pi^1_1$ class are not bounded below $\omega_1^{\mathrm{CK}}$ in general.
:::

The first example is the higher counterpart of the enumeration of a $\Sigma^0_1$ class; the second shows what is new. A member $Y$ of the second class coding a well-ordering of type $\omega_1^{\mathrm{CK}}$ enters at stage $\omega_1^{\mathrm{CK}}$, and $\omega_1^{\mathrm{CK}}$ is $Y$-computable. The next proposition says that this is the only way to enter at a non-computable stage.

:::proposition{#fact-pi11-stages}
1. For every $p$ and every $a \in \mathcal O$, the stage $\mathcal A^p_{|a|}$ is $\Delta^1_1$, uniformly: there are $\Pi^1_1$ relations $P_<(p, a, Y)$ and $P_\geq(p, a, Y)$ such that, for $a \in \mathcal O$, the class $\mathcal A^p_{|a|}$ is defined by $P_<(p, a, \cdot)$ and its complement by $P_\geq(p, a, \cdot)$.
2. If $Y \in \mathcal A^p$, then $Y$ enters $\mathcal A^p$ at a stage less than $\omega_1^Y$. In particular, if $\omega_1^Y = \omega_1^{\mathrm{CK}}$, then $Y \in \mathcal A^p_\alpha$ for some $\alpha < \omega_1^{\mathrm{CK}}$.
:::

The idea of (1) is the stage comparison of :ref{to="descriptive-set-theory/norms"}: compare the tree $T^Y_p$ with a fixed computable tree of rank $|a|$ by strictly monotone maps.

:::proof{of=fact-pi11-stages}
1. By :ref{#prop-constructive-computable}, there is a total computable function mapping every $a \in \mathcal O$ to an index of a computable well-ordering $L$ of type $|a|$; let $S_a$ be the tree $D_L$ of :ref{#prop-descending-tree}. It is computable, uniformly in $a$, contains the empty sequence, and for $a \in \mathcal O$ it is well-founded of rank $|a|$. Fix $a \in \mathcal O$ and suppose $T = T^Y_p$ defined. By :ref{#lem-rank-comparison}, $|a| \leq \rho(T)$ if and only if there is a strictly monotone map from $S_a$ to $T$, so
$$
Y \in \mathcal A^p_{|a|} \iff T^Y_p \text{ is defined} \wedge \neg \exists g\ (g : S_a \to T^Y_p \text{ is strictly monotone}).
$$
The right-hand side is $\Pi^1_1$ in $(p, a, Y)$: the first conjunct is arithmetic, and the second is a universal function quantifier in front of an arithmetic condition. This is $P_<$. For the complement, since $S_a$ is well-founded, the display after :ref{#lem-rank-comparison} gives $\rho(T) < \rho(S_a)$ if and only if $\rho(T) \leq \rho((S_a)_{\langle x \rangle})$ for some $x$ with $\langle x \rangle \in S_a$. So
$$
Y \notin \mathcal A^p_{|a|} \iff T^Y_p \text{ is not defined} \vee \forall x\, \forall g\ \neg \big( \langle x \rangle \in S_a \wedge g : T^Y_p \to (S_a)_{\langle x \rangle} \text{ is strictly monotone} \big),
$$
a $\Pi^1_1$ relation $P_\geq$. Both relations are written uniformly in $p$ and $a$; they define the stage and its complement when $a \in \mathcal O$.
2. The tree $T^Y_p$ is $Y$-computable and well-founded. Its Kleene–Brouwer ordering is a $Y$-computable well-ordering of type at least its rank (:ref{#thm-kleene-brouwer}), so this rank is less than $\omega_1^Y$. If $\omega_1^Y = \omega_1^{\mathrm{CK}}$, the rank $\alpha$ is a computable ordinal, and $Y \in \mathcal A^p_{\alpha + 1}$ with $\alpha + 1 < \omega_1^{\mathrm{CK}}$.
:::

:::quiz[the stages of a Π¹₁ class]
In the proof of :ref{#fact-pi11-stages} (1), why are two different comparisons used for the stage and for its complement?

- [x] Because the existence of a strictly monotone map is a $\Sigma^1_1$ condition, so each relation must be written as the negation of such an existence: "$S_a$ does not map into $T^Y_p$" for the stage, "$T^Y_p$ maps into no $(S_a)_{\langle x \rangle}$" for its complement.
- [ ] Because $T^Y_p$ may be ill-founded.

  The comparison of :ref{#lem-rank-comparison} holds for all trees; ill-founded trees are handled by $\rho = \infty$.
- [ ] Because $S_a$ is only c.e.

  $S_a$ is computable, uniformly in $a$; the point is the complexity of the quantifier over maps.

---

Where is the hypothesis $a \in \mathcal O$ used?

- [x] To know that $S_a$ is well-founded of rank $|a|$, which is needed for the second equivalence and for the relations to define the stage $|a|$.
- [ ] To know that $S_a$ is a tree.

  $S_a$ is the tree of descending sequences of a relation, for every $a$; only its well-foundedness and its rank depend on $a \in \mathcal O$.
- [ ] To make the relations $P_<$ and $P_\geq$ arithmetic.

  They are $\Pi^1_1$ for every $a$; for $a \notin \mathcal O$ they define classes with no meaning.
:::

## Δ¹₁ classes are bounded stages

For sets of numbers, a $\Pi^1_1$ set is $\Delta^1_1$ exactly when it is enumerated before a computable stage (:ref{#thm-pi11-stages}). The same holds for classes, and the proof is the same: the boundedness theorem, now applied to the Kleene–Brouwer orderings of the trees $T^Y_p$.

:::proposition{#prop-class-boundedness}
If $\mathcal S \subseteq \mathcal A^p$ is a $\Sigma^1_1$ class, then there is a computable ordinal $\alpha$ with $\mathcal S \subseteq \mathcal A^p_\alpha$.
:::

:::proof{of=prop-class-boundedness}
Let $\gamma$ be the supremum of the ranks of the trees $T^Y_p$ for $Y \in \mathcal S$, and suppose $\gamma \geq \omega_1^{\mathrm{CK}}$. Then for every index $e$,
$$
e \in \mathrm{WO} \iff e \text{ is an index of a computable linear order} \wedge \exists Y\, \exists h\, \big( Y \in \mathcal S \wedge h \text{ embeds } L_e \text{ into } (T^Y_p, <_{\mathrm{KB}}) \big),
$$
where "$h$ embeds" means that $h$ is an order-preserving injection. If $e \in \mathrm{WO}$, then $|L_e| < \omega_1^{\mathrm{CK}} \leq \gamma$, so some $Y \in \mathcal S$ has $\rho(T^Y_p) > |L_e|$; the ordering $(T^Y_p, <_{\mathrm{KB}})$ is a well-ordering of type at least this rank (:ref{#thm-kleene-brouwer}), and $L_e$ embeds into it by the comparison theorem (:ref{#thm-wo-comparison}). Conversely, a linear order that embeds into a well-ordering is a well-ordering, and $(T^Y_p, <_{\mathrm{KB}})$ is one since $Y \in \mathcal A^p$. The right-hand side is $\Sigma^1_1$, which contradicts :ref{#prop-pi11-not-sigma11}. So $\gamma < \omega_1^{\mathrm{CK}}$, and $\alpha = \gamma + 1$ works.
:::

The technique is **boundedness**: a $\Sigma^1_1$ family of well-orderings, here the Kleene–Brouwer orderings of the trees $T^Y_p$ for $Y \in \mathcal S$, cannot reach $\omega_1^{\mathrm{CK}}$, since otherwise it would define $\mathrm{WO}$ (:ref{#thm-boundedness}). The members of $\mathcal S$ may themselves compute large ordinals; only the stages at which they enter $\mathcal A^p$ are bounded.

:::corollary{#cor-delta11-stage}
A class is $\Delta^1_1$ if and only if it is a stage $\mathcal A^p_{|a|}$ for some $p$ and some $a \in \mathcal O$.
:::

:::proof{of=cor-delta11-stage}
A stage $\mathcal A^p_{|a|}$ with $a \in \mathcal O$ is $\Delta^1_1$ by :ref{#fact-pi11-stages} (1). Conversely, a $\Delta^1_1$ class $\mathcal D$ is $\Pi^1_1$, so $\mathcal D = \mathcal A^p$ for some $p$, and it is a $\Sigma^1_1$ subclass of $\mathcal A^p$. By :ref{#prop-class-boundedness}, $\mathcal D \subseteq \mathcal A^p_\alpha \subseteq \mathcal A^p = \mathcal D$ for a computable ordinal $\alpha$, which has a notation $a \in \mathcal O$ (:ref{#cor-constructive-computable}).
:::

:::example{#ex-delta11-classes}
1. If $X$ is hyperarithmetic, the singleton $\{ X \}$ is $\Delta^1_1$. The relation $n \in X$ has a $\Pi^1_1$ and a $\Sigma^1_1$ definition (:ref{#prop-h-delta11}). In "$\forall n\, (n \in Y \leftrightarrow n \in X)$", using the $\Pi^1_1$ definition in the implication from $n \in Y$ and the $\Sigma^1_1$ one in the converse implication gives a $\Pi^1_1$ definition of $\{ X \}$; exchanging the two gives a $\Sigma^1_1$ one.
2. More generally, a class defined by an arithmetic formula with a hyperarithmetic set $A$ as a parameter is $\Delta^1_1$: in prenex form, replace each atomic formula $n \in A$ by the $\Pi^1_1$ or the $\Sigma^1_1$ definition according to whether it occurs positively or negatively, and use that $\Pi^1_1$ and $\Sigma^1_1$ relations are closed under number quantifiers. For instance, the class $\{ Y : Y \leq_T A \}$ and the intersection of a Martin-Löf test relative to $A$ are $\Delta^1_1$.
3. The class of $Y$ coding a well-founded relation, in :ref{#ex-class-stages} (2), is $\Pi^1_1$ but not $\Sigma^1_1$: its members enter at stages unbounded below $\omega_1$, so it is not included in any stage $\mathcal A^p_\alpha$ with $\alpha$ computable, as :ref{#prop-class-boundedness} would require.
:::

## Exercises

::::exercise{difficulty=1}
Let $\mathcal S$ be a $\Sigma^1_1$ class of sequences that code well-orderings. Show that the order types of the members of $\mathcal S$ are bounded by a computable ordinal.

:::solution
$\mathcal S$ is included in the class of well-founded relations of :ref{#ex-class-stages} (2), and a member coding a well-ordering $L$ enters it at stage $|L|$. By :ref{#prop-class-boundedness}, these stages are bounded by a computable ordinal. This is the boundedness theorem for classes; for instance, a $\Sigma^1_1$ class of codes of well-orderings cannot contain a code of every computable ordinal.
:::
::::

::::exercise{difficulty=1}
Let $\mathcal A = \mathcal A^p$ be a $\Pi^1_1$ class. Show that the class of $Y \in \mathcal A$ that enter $\mathcal A$ at a stage at least $\omega_1^{\mathrm{CK}}$ is included in the class of $Y$ with $\omega_1^Y > \omega_1^{\mathrm{CK}}$. Give an example of a $\Pi^1_1$ class in which this class of late members is non-empty.

:::solution
If $Y \in \mathcal A$ enters at stage $\gamma \geq \omega_1^{\mathrm{CK}}$, then $\gamma < \omega_1^Y$ by :ref{#fact-pi11-stages} (2), so $\omega_1^Y > \omega_1^{\mathrm{CK}}$. In the class of well-founded relations (:ref{#ex-class-stages} (2)), a sequence coding a well-ordering of type $\omega_1^{\mathrm{CK}}$ enters at stage $\omega_1^{\mathrm{CK}}$.
:::
::::

## Notes and references

The normal form of $\Pi^1_1$ classes and their decomposition along the ordinals go back to Lusin and Sierpiński in classical descriptive set theory; the effective version is due to Kleene and Spector. Nies describes $\Pi^1_1$ classes by Turing functionals producing linear orders, whose order types are the stages (his Theorem 9.1.3 and the Approximation Lemma 9.1.4); trees are used here, so that the stage comparison of the course on effective descriptive set theory applies directly. The boundedness of $\Sigma^1_1$ subclasses is the class form of Spector's boundedness theorem; :ref{#cor-delta11-stage} is the effective counterpart of the classical fact that an analytic subset of a co-analytic set is included in one of its constituents.

- A. Nies, *Computability and Randomness*, Oxford University Press, 2009, Section 9.1.
- G. E. Sacks, *Higher Recursion Theory*, Springer, 1990.
- A. S. Kechris, *Classical Descriptive Set Theory*, Springer, 1995.
