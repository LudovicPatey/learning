The measure $\lambda$ is defined on the Borel classes, and $\Pi^1_1$ classes need not be Borel: the class of well-founded relations is not. This lesson shows that $\Pi^1_1$ classes are nevertheless measurable, by the decomposition into stages of the previous lesson: the stages are Borel, and some countable stage adds no measure, which leaves only a null class beyond it. It then states the two facts on the measure of $\Delta^1_1$ classes that the course admits: their measures are hyperarithmetic reals, uniformly, and they can be approximated from outside by open classes generated by sets of strings c.e. in hyperarithmetic sets. These are the higher counterparts of the left-c.e. measure of $\Sigma^0_1$ classes and of the outer regularity of the measure.

## Lusin's theorem

The measure $\lambda$ is defined on the Borel classes (:ref{#fact-lebesgue-measure}). A class $\mathcal X$ is **measurable** if there are Borel classes $\mathcal B$ and $\mathcal Z$ with $\lambda(\mathcal Z) = 0$ such that $\mathcal X$ and $\mathcal B$ differ only inside $\mathcal Z$: $(\mathcal X \setminus \mathcal B) \cup (\mathcal B \setminus \mathcal X) \subseteq \mathcal Z$. Then $\lambda(\mathcal X)$ is defined as $\lambda(\mathcal B)$; two such Borel classes differ by a null class, so the value does not depend on the choice. Measurable classes are closed under complements and countable unions, and $\lambda$ is countably additive on them. A **null** class is a measurable class of measure $0$, that is, a subclass of a null Borel class.

The stages of a $\Pi^1_1$ class are Borel, by a recursion that follows the definition of the rank.

:::lemma{#lem-stages-borel}
For every $p$ and every countable ordinal $\alpha$, the stage $\mathcal A^p_\alpha$ is Borel. Moreover, for every $\sigma \in \nat^{<\nat}$, the class $\mathcal N^\sigma_\alpha$ of $Y$ such that $T^Y_p$ is defined, $\sigma \in T^Y_p$ and $\mathrm{rk}_{T^Y_p}(\sigma) < \alpha$, is Borel.
:::

:::proof{of=lem-stages-borel}
Write $T^Y = T^Y_p$, and let $\mathcal T$ be the class of $Y$ for which $T^Y$ is defined, an arithmetic and hence Borel class. For each $\sigma$, the class $\mathcal T_\sigma$ of $Y \in \mathcal T$ with $\sigma \in T^Y$ is Borel as well. We show by induction on $\alpha$ that all the classes $\mathcal N^\sigma_\alpha$ are Borel. A node has rank less than $\beta + 1$ if and only if all its immediate successors in the tree have rank less than $\beta$, and rank less than a limit $\lambda$ if and only if it has rank less than some $\beta < \lambda$. So
$$
\mathcal N^\sigma_0 = \emptyset, \qquad \mathcal N^\sigma_{\beta + 1} = \mathcal T_\sigma \cap \bigcap_{n} \big( (\mathcal T \setminus \mathcal T_{\sigma n}) \cup \mathcal N^{\sigma n}_\beta \big), \qquad \mathcal N^\sigma_\lambda = \bigcup_{\beta < \lambda} \mathcal N^\sigma_\beta,
$$
where the union is countable since $\lambda$ is countable. Finally $\mathcal A^p_\alpha = \mathcal N^{\langle\rangle}_\alpha$, since the root has the rank of the tree.
:::

:::theorem[Lusin]{#thm-lusin}
Every $\Pi^1_1$ class and every $\Sigma^1_1$ class is measurable. More precisely, for every $p$ there is a countable ordinal $\beta$ such that $\mathcal A^p \setminus \mathcal A^p_{\beta + 1}$ is included in a null Borel class.
:::

The idea is that the stages cannot keep adding measure forever. The measures $\lambda(\mathcal A^p_\alpha)$ are nondecreasing in $\alpha$ and bounded by $1$, so they increase strictly at only countably many stages; at any other stage $\beta$, the sequences entering at exactly stage $\beta$ form a null class. A sequence entering after $\beta$ has, in its tree, a node of rank exactly $\beta$, so the same argument applied to all the nodes captures it in a null class (:ref{#fig-stage-measure}).

:::proof{of=thm-lusin}
Fix $p$, write $T^Y = T^Y_p$, and let $\mathcal N^\sigma_\alpha$ be the classes of :ref{#lem-stages-borel}. For each $\sigma$, the function $\alpha \mapsto \lambda(\mathcal N^\sigma_\alpha)$ on countable ordinals is nondecreasing. Let $I_\sigma$ be the set of $\alpha$ with $\lambda(\mathcal N^\sigma_{\alpha + 1}) > \lambda(\mathcal N^\sigma_\alpha)$. The open intervals $\big( \lambda(\mathcal N^\sigma_\alpha), \lambda(\mathcal N^\sigma_{\alpha + 1}) \big)$ for $\alpha \in I_\sigma$ are pairwise disjoint, and each contains a rational, so $I_\sigma$ is countable. The union of the countably many sets $I_\sigma$ is a countable set of countable ordinals, so there is a countable ordinal $\beta$ in none of them. For every $\sigma$, the Borel class $\mathcal N^\sigma_{\beta + 1} \setminus \mathcal N^\sigma_\beta$ of the $Y$ in which $\sigma$ has rank exactly $\beta$ is then null, and so is their union $\mathcal Z$.

Let $Y \in \mathcal A^p \setminus \mathcal A^p_{\beta + 1}$, so that $T^Y$ is well-founded of rank greater than $\beta$. We find a node of rank exactly $\beta$ by descending in the tree. Start from the root. If the current node $\tau$ has rank greater than $\beta$, then, since its rank is the supremum of the ordinals $\mathrm{rk}(\tau n) + 1$, some immediate successor $\tau n$ has rank at least $\beta$; stop if it is $\beta$, and continue from $\tau n$ otherwise. The ranks strictly decrease along the descent, so it stops, at a node $\sigma$ of rank $\beta$. Then $Y \in \mathcal N^\sigma_{\beta + 1} \setminus \mathcal N^\sigma_\beta \subseteq \mathcal Z$.

So $\mathcal A^p \setminus \mathcal A^p_{\beta + 1} \subseteq \mathcal Z$, and $\mathcal A^p$ differs from the Borel class $\mathcal A^p_{\beta + 1}$ (:ref{#lem-stages-borel}) only inside $\mathcal Z$: it is measurable, of measure $\lambda(\mathcal A^p_{\beta + 1})$. Every $\Pi^1_1$ class is some $\mathcal A^p$, and a $\Sigma^1_1$ class is the complement of a $\Pi^1_1$ class.
:::

The proof is a **measure-theoretic stabilization**: a nondecreasing family of measures indexed by the countable ordinals increases strictly at only countably many indices, because pairwise disjoint open intervals of reals are countably many; the countable ordinals are not, so some index adds no measure. By :ref{#lem-stages-borel} and :ref{#cor-delta11-stage}, every $\Delta^1_1$ class is Borel; this is the effective half of Suslin's theorem that the classes both analytic and co-analytic are Borel.

## The measure of Δ¹₁ classes

The measure of a $\Sigma^0_1$ class is a left-c.e. real, uniformly in an index (:ref{#prop-measure-effective}). The higher counterpart says that the measure of a $\Delta^1_1$ class is a hyperarithmetic real, uniformly in a pair of $\Pi^1_1$ definitions of the class and of its complement. We admit it, together with an approximation of $\Delta^1_1$ classes by open classes that extends the outer regularity of the measure. Both are proved by effective transfinite recursion along the Borel hierarchy (Sacks, Chapter IV).

:::fact{#fact-higher-borel}
1. *Measure.* Let $P(k, Y)$ and $P'(k, Y)$ be $\Pi^1_1$ relations, and let $K$ be the set of numbers $k$ such that the classes defined by $P(k, \cdot)$ and $P'(k, \cdot)$ are complements of each other. There is a $\Pi^1_1$ relation $M(k, q)$ such that, for $k \in K$ and rational $q$, $M(k, q)$ holds if and only if $\lambda(\{ Y : P(k, Y) \}) > q$.
2. *Approximation.* For every $\Delta^1_1$ class $\mathcal D$, there are a hyperarithmetic set $A$ and sets of strings $W_k$, uniformly c.e. in $A$, such that $\mathcal D \subseteq [W_k]$ and $\lambda([W_k] \setminus \mathcal D) \leq 2^{-k}$ for every $k$.
:::

In (2), $[W]$ denotes the open class of sequences extending some member of the set of strings $W$. A $\Delta^1_1$ class is $\Sigma^0_\alpha$ for some computable ordinal $\alpha$, and (2) is proved by induction on $\alpha$: a $\Sigma^0_\alpha$ class is included in an open class, generated by a set c.e. in $\emptyset^{(\alpha)}$, whose measure exceeds its own by at most $\varepsilon$. For $\alpha = 1$ there is nothing to do; the inductive step is the argument of outer regularity (:ref{#fact-lebesgue-measure}), carried out effectively in the iterated jumps.

Item (1) is used as follows. For $k \in K$, both comparisons of the measure of $\mathcal D_k = \{ Y : P(k, Y) \}$ with a rational are $\Pi^1_1$:
$$
\lambda(\mathcal D_k) > q \iff M(k, q), \qquad \lambda(\mathcal D_k) < q \iff M'(k, 1 - q),
$$
where $M'$ is given by (1) with the roles of $P$ and $P'$ exchanged, since the complement of $\mathcal D_k$ has measure $1 - \lambda(\mathcal D_k)$. By :ref{#fact-pi11-stages} (1), this applies to the stages $\mathcal A^p_{|a|}$, with $k = (p, a)$, $P = P_<$, $P' = P_\geq$, and $K \supseteq \nat \times \mathcal O$. In particular, the left and right cuts of the measure of a $\Delta^1_1$ class are $\Delta^1_1$ sets of rationals: this measure is a hyperarithmetic real. Nies states the measure lemma in a stronger form, for every $\Pi^1_1$ relation $P$ (his Measure Lemma 9.1.10): the measure of a $\Pi^1_1$ class is left-$\Pi^1_1$, uniformly. The course only uses the $\Delta^1_1$ case.

:::example{#ex-measure-pi11}
The class $\mathcal A$ of well-founded relations of :ref{#ex-class-stages} (2) is null. A relation coded by a sequence $Y$ chosen at random is well-founded only if it contains no pair $\langle x, x \rangle$, since such a pair gives the descending sequence $x, x, x, \dots$; and each of the infinitely many pairs $\langle x, x \rangle$ belongs to $Y$ independently with probability $\frac12$. This class is $\Pi^1_1$ and not $\Sigma^1_1$ (:ref{#ex-delta11-classes} (3)), but it is included in the null Borel class of sequences containing no pair $\langle x, x \rangle$, so it is null.
:::

## Exercises

::::exercise{difficulty=2}
Show that for every $\Pi^1_1$ class $\mathcal A$ and every rational $q < \lambda(\mathcal A)$, there is a countable ordinal $\alpha$ with $\lambda(\mathcal A_\alpha) > q$, and that $\lambda(\mathcal A) = \sup_{\alpha < \omega_1} \lambda(\mathcal A_\alpha)$.

:::solution
By :ref{#thm-lusin}, there is a countable $\beta$ such that $\mathcal A \setminus \mathcal A_{\beta + 1}$ is null, so $\lambda(\mathcal A) = \lambda(\mathcal A_{\beta + 1})$, and $\alpha = \beta + 1$ works. Since $\mathcal A_\alpha \subseteq \mathcal A$ for every $\alpha$, the supremum is at most $\lambda(\mathcal A)$, and it is attained at $\beta + 1$. The lesson on the Sacks–Tanaka theorem shows that $\alpha$ can be taken computable.
:::
::::

## Notes and references

Lusin proved that analytic and co-analytic sets are measurable. The proof given here, by stabilization of the measures of the stages, is the one in Nies's book (Theorem 9.1.9), written with trees instead of linear orders; Monin and Patey give the same argument in their chapter *Higher randomness*. The measure fact (item 1 of :ref{#fact-higher-borel}) is a special case of Nies's Measure Lemma 9.1.10, where it is referred to Sacks's book; Hjorth and Nies cite it as an exercise in Sacks's Chapter IV. The approximation (item 2) is the transfinite extension of the approximation of $\Sigma^0_n$ classes by open classes; Monin and Patey prove it as a lemma of their chapter *Higher randomness*, and Nies refers it to Sacks's Chapter IV in the proof of his Theorem 9.3.3.

- A. Nies, *Computability and Randomness*, Oxford University Press, 2009, Section 9.1.
- G. E. Sacks, *Higher Recursion Theory*, Springer, 1990, Chapter IV.
- G. Hjorth and A. Nies, *Randomness via effective descriptive set theory*, Journal of the London Mathematical Society 75 (2007), 495–508.
- A. S. Kechris, *Classical Descriptive Set Theory*, Springer, 1995.
