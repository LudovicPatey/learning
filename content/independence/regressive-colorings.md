The previous lesson proved that the Paris–Harrington principle is true and that each of its instances of fixed arity is provable in $\mathrm{PA}$. To show that $\mathrm{PA}$ does not prove the principle, the method of indicators requires, in any interval $[a, b]$ that is relatively large to a non-standard degree, a cut that satisfies $\mathrm{PA}$. The cut will be generated by **indiscernibles**: elements of $[a, b]$ such that tuples of them satisfy the same formulas with small parameters. This lesson provides the combinatorics: relatively large homogeneous sets give min-homogeneous sets for regressive colorings (Kanamori and McAloon), and a well-chosen regressive coloring turns min-homogeneity into indiscernibility for any coded family of relations. The next lesson builds the cut.

## Regressive colorings

Relative largeness is used through a consequence due to Kanamori and McAloon: colorings with unboundedly many colors, provided each value is below the least element of its argument, have large sets on which the value depends only on the least element.

:::definition[Kanamori, McAloon]{#def-regressive}
A function $f : [X]^n \to \nat$ is **regressive** if $f(s) < \min s$ for every $s \in [X]^n$. A set $H \subseteq X$ is **min-homogeneous** for $f$ if $f(s) = f(t)$ for all $s, t \in [H]^n$ with $\min s = \min t$.
:::

For instance, $f(\{ x, y \}) = $ the remainder of $y$ modulo $x$, on $[1, \infty)$, is regressive; a set $\{ x_0 < x_1 < \cdots \}$ is min-homogeneous when, for each $i$, all $x_j$ with $j > i$ have the same remainder modulo $x_i$. Homogeneity cannot be asked for (exercise below).

:::lemma{#lem-ph-regressive}
Let $n \geq 2$, $k \geq 1$ and $1 \leq a \leq b$. If $[a + n, b + n] \to_* (k + n - 1)^{n+1}_{2^{n-1}}$, then every regressive $f : [[a, b]]^n \to \nat$ has a min-homogeneous set with at least $k$ elements.
:::

The idea is to color an $(n+1)$-set $t = \{ t_0 < \cdots < t_n \}$ by recording, for each $j$ between $1$ and $n - 1$, whether the two $n$-sets obtained by removing $t_j$ or $t_{j+1}$ have the same value. On a homogeneous set, a coordinate other than the least can then be moved without changing the value, and the moves connect any two $n$-sets with the same minimum. The homogeneous color must say "same value" everywhere: otherwise, many $n$-sets with the same minimum would have pairwise distinct values, all below that minimum, and relative largeness gives more such sets than there are possible values.

:::proof{of=lem-ph-regressive}
For $t = \{ t_0 < \cdots < t_n \} \subseteq [a, b]$, let $C(t)$ be the set of $j \in \{ 1, \dots, n - 1 \}$ such that $f(t \setminus \{ t_j \}) = f(t \setminus \{ t_{j+1} \})$, coded as a number below $2^{n-1}$. The coloring $C'(t) = C(t - n)$ of $[[a + n, b + n]]^{n+1}$, where $t - n$ is the translate of $t$, has a relatively large homogeneous set $H'$ with at least $k + n - 1$ elements. Its translate $H = H' - n \subseteq [a, b]$ is homogeneous for $C$, has $N \geq k + n - 1$ elements, and $N > \min H' = \min H + n$. Write $H = \{ x_0 < \cdots < x_{N-1} \}$.

*The color is $\{ 1, \dots, n - 1 \}$.* Suppose $j \notin C$ on $[H]^{n+1}$. For $y \in H$ with $x_{j-1} < y < x_{N-n+j+1}$, with the convention $x_N = \infty$, let
$$
s_y = \{ x_0, \dots, x_{j-1} \} \cup \{ y \} \cup \{ x_{N-n+j+1}, \dots, x_{N-1} \},
$$
an $n$-set in which $y$ has position $j$. For $y < y'$ of this kind, $t = s_y \cup \{ y' \}$ is an $(n+1)$-set with $t_j = y$ and $t_{j+1} = y'$; removing $t_{j+1}$ gives $s_y$, removing $t_j$ gives $s_{y'}$, and $j \notin C(t)$ gives $f(s_y) \neq f(s_{y'})$. There are $N - n + 1$ such $y$, namely $x_j, \dots, x_{N-n+j}$, and the values $f(s_y)$ are pairwise distinct and below $\min s_y = x_0$, since $f$ is regressive. So $N - n + 1 \leq x_0$, contradicting $N > x_0 + n$.

*Moving coordinates.* So $C = \{ 1, \dots, n - 1 \}$ on $[H]^{n+1}$. Let $u = \{ u_0 < \cdots < u_{n-1} \} \subseteq H$, $1 \leq j \leq n - 1$, and $y \in H \setminus u$ with $u_{j-1} < y < u_{j+1}$ (where $u_n = \infty$); let $u'$ be $u$ with $u_j$ replaced by $y$. Then $t = u \cup \{ y \}$ is an $(n+1)$-set in which $u_j$ and $y$ are adjacent, at positions $j$ and $j + 1$ in some order, and removing one or the other gives $u$ and $u'$; as $j \in C(t)$, $f(u) = f(u')$.

*Min-homogeneity.* Let $H_0$ be $H$ without its $n - 1$ largest elements $w_1 < \cdots < w_{n-1}$; $|H_0| \geq k$. Let $u \in [H_0]^n$. Move $u_{n-1}$ to $w_{n-1}$, then $u_{n-2}$ to $w_{n-2}$, and so on down to $u_1$ to $w_1$: at each step the new value lies strictly between the coordinate below and the one above, so the move is allowed. Hence $f(u) = f(\{ u_0, w_1, \dots, w_{n-1} \})$, which depends only on $\min u = u_0$. So $H_0$ is min-homogeneous.
:::

The translation by $n$ trades the relative largeness of $H'$ for the stronger condition $|H| > \min H + n$, which the counting argument requires; this is why the hypothesis concerns $[a + n, b + n]$.

:::quiz[regressive colorings]
In the proof of :ref{#lem-ph-regressive}, where is it used that $f$ is regressive?

- [x] To bound the number of possible values of $f(s_y)$ by $x_0 = \min s_y$, which the pairwise distinct values exceed.
- [ ] To show that the moves of coordinates preserve the value of $f$.

  The moves only use the homogeneous color $C = \{ 1, \dots, n - 1 \}$.
- [ ] To make $C$ a coloring with finitely many colors.

  $C$ takes values below $2^{n-1}$ whatever $f$ is.

---

Why is the least coordinate $u_0$ never moved?

- [x] Every comparison made by $C$ keeps $t_0$ in both $n$-sets, so the colors give no information on what happens when the minimum changes; and min-homogeneity does not require it.
- [ ] Because $u_0$ is in $H_0$.

  All coordinates of $u$ are in $H_0$.
- [ ] Because moving it would break regressiveness.

  Regressiveness is a property of $f$, not of the moves.
:::


## Indiscernibility from a regressive coloring

Min-homogeneity is turned into indiscernibility by a coloring that records where two blocks of a set differ. We state the construction in a model $M$ of $\mathrm I\Sigma_1$, which may be $\nat$. Let $R = (R_j)_{j < e}$ be a family of relations $R_j \subseteq [0, b]^{1 + m}$, coded in $M$, with $m \geq 1$; we read $R_j(x; \bar y)$ as a formula with parameter $x$ and $m$ indices. On $[[1, b]]^{2m+1}$, define the coloring $f_R$ as follows: for $s = \{ y_0 \} \cup \bar y \cup \bar z$, where $y_0 < \bar y < \bar z$ and $\bar y, \bar z$ are the next $m$ and the last $m$ elements of $s$,
$$
f_R(s) = \begin{cases} x + 1 & \text{for the least } x \text{ with } x + 1 < y_0 \text{ such that } R_j(x; \bar y) \not\leftrightarrow R_j(x; \bar z) \text{ for some } j < e, \\ 0 & \text{if there is no such } x. \end{cases}
$$
It is regressive. A min-homogeneous set makes $f_R$ vanish, because of a counting argument: a nonzero value $x + 1$ at the minimum $h$ would make all blocks above $h$ pairwise different at the same parameter $x$, and there are at most $2^e$ patterns of truth values.

:::lemma{#lem-diag-from-regressive}
Let $H$ be min-homogeneous for $f_R$, and let $H_2$ be $H$ without its $(2^e + 2) m$ largest elements. Then for every $h \in H_2$, every $x$ with $x + 1 < h$, every $j < e$ and all increasing $m$-tuples $\bar y, \bar z$ from $H \setminus \{ \text{the } m \text{ largest elements} \}$ above $h$, $R_j(x; \bar y) \leftrightarrow R_j(x; \bar z)$.
:::

:::proof{of=lem-diag-from-regressive}
*Step 1.* Let $h \in H_2$, and let $\bar u < \bar u'$ be $m$-tuples from $H$ above $h$, the first entirely below the second. We show $f_R(\{ h \} \cup \bar u \cup \bar u') = 0$. Suppose the value is $x + 1$. Above $h$ there are at least $(2^e + 2) m$ elements of $H$; choose among them $L = 2^e + 1$ consecutive blocks $\bar u_1 < \bar u_2 < \cdots < \bar u_L$ of $m$ elements. For $p < q$, the set $\{ h \} \cup \bar u_p \cup \bar u_q$ has minimum $h$, so by min-homogeneity $f_R$ takes the value $x + 1$ on it: some $j < e$ has $R_j(x; \bar u_p) \not\leftrightarrow R_j(x; \bar u_q)$. So the vectors $(R_j(x; \bar u_p))_{j < e} \in \{ 0, 1 \}^e$, for $p = 1, \dots, L$, are pairwise distinct, which is impossible since $L > 2^e$.

*Step 2.* Let $\bar w$ be the $m$ largest elements of $H$. For $\bar y$ as in the statement, $\bar y$ lies entirely below $\bar w$, and Step 1 gives $f_R(\{ h \} \cup \bar y \cup \bar w) = 0$: for every $x$ with $x + 1 < h$ and every $j < e$, $R_j(x; \bar y) \leftrightarrow R_j(x; \bar w)$. The same holds for $\bar z$, and the two equivalences give the claim.
:::

Step 1 is the **pigeonhole principle** for $2^e + 1$ objects in $2^e$ boxes, applied in $M$; it holds for non-standard $e$, which lesson 7 needs so that $R$ contains every standard formula. Step 2 compares $\bar y$ and $\bar z$ with a common block above both, since $f_R$ only compares a block with a block entirely above it.

:::quiz[diagonal indiscernibles from a regressive coloring]
In the proof of :ref{#lem-diag-from-regressive}, why does $f_R$ return $x + 1$ rather than $x$?

- [x] The value $0$ must mean "no difference"; if $f_R$ returned $x$, the value $0$ would be ambiguous between a difference at the parameter $0$ and no difference at all.
- [ ] To make $f_R$ regressive.

  Returning $x$ would also be regressive; the shift requires the restriction $x + 1 < y_0$ to keep regressiveness.
- [ ] Because min-homogeneity fails for the value $0$.

  Min-homogeneity concerns all values alike.

:::

## Formalization in models of IΣ₁

The arguments of this lesson are finite combinatorics with coded objects: colorings, homogeneous sets and translates are coded in $\mathrm I\Delta_0 + \mathrm{exp}$ by bounded definitions, and the only principle used beyond bounded induction is the pigeonhole principle for coded functions (:ref{#ex-finite-pigeonhole}). So they hold in every model of $\mathrm I\Sigma_1$, for non-standard parameters and colorings coded in the model. This is how :ref{#lem-ph-regressive} and :ref{#lem-diag-from-regressive} are used in lesson 7, inside a model of $\mathrm I\Sigma_1$ and with a non-standard number $e$ of relations.

## Exercises

::::exercise{difficulty=2}
Let $f : [X]^2 \to \nat$, $f(\{ x, y \}) = x - 1$, on $X = [1, b]$. Show that $f$ is regressive, that every set is min-homogeneous for $f$, and that a homogeneous set for $f$ has at most two elements. Deduce that "min-homogeneous" cannot be replaced by "homogeneous" in :ref{#lem-ph-regressive}.

:::solution
$f(\{ x, y \}) = x - 1 < x = \min \{ x, y \}$. The value depends only on the minimum, so every set is min-homogeneous. If $x < y < z$ are in a homogeneous set, $f(\{ x, y \}) = x - 1 \neq y - 1 = f(\{ y, z \})$. So no homogeneous set has three elements, while the lemma, for $k \geq 3$, provides min-homogeneous sets of size $k$ when $b$ is large enough.
:::
::::

## Notes and references

Regressive colorings and min-homogeneous sets are due to Kanamori and McAloon (1987), who proved that the corresponding principle, "for all $n, k$ there is $m$ such that every regressive coloring of $[[1, m]]^n$ has a min-homogeneous set with $k$ elements", is true and unprovable in $\mathrm{PA}$, and equivalent to $\mathrm{PH}$. :ref{#lem-ph-regressive} is one direction of this equivalence, with a proof written for this course. The coloring $f_R$ and :ref{#lem-diag-from-regressive} adapt the construction of diagonal indiscernibles in Kanamori and McAloon's paper. Bovykin (2009) gives a short model-theoretic account of the Kanamori–McAloon principle and of its threshold versions.

- A. Kanamori and K. McAloon, *On Gödel incompleteness and finite combinatorics*, Annals of Pure and Applied Logic 33 (1987), 23–41.
- A. Bovykin, *Brief introduction to unprovability*, in Logic Colloquium 2006, Lecture Notes in Logic 32, Cambridge University Press, 2009.
