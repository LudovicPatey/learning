A sequence is random if it has no property that can be detected effectively and that only a null class of sequences shares. Martin-Löf (1966) made this precise by requiring the null class to be covered by open classes of measure at most $2^{-n}$, enumerated uniformly in $n$. The rate $2^{-n}$ allows all such tests to be combined into a single one, which is the main technical feature of the definition. This lesson introduces the tests, proves the existence of a universal test, shows that random sequences satisfy the law of large numbers, and gives an equivalent definition due to Solovay.

## Tests

A sequence of classes $(\mathcal U_n)_{n \in \nat}$ is **uniformly $\Sigma^0_1$** if there is a c.e. set $W \subseteq \nat \times \bstr$ such that $\mathcal U_n = [W^{[n]}]^{\prec}$ for every $n$, where $W^{[n]} = \{ \sigma : (n, \sigma) \in W \}$. An index of $W$ is an **index** of the sequence.

:::definition[Martin-Löf]{#def-ml-test}
A **Martin-Löf test** is a uniformly $\Sigma^0_1$ sequence $(\mathcal U_n)$ with $\lambda(\mathcal U_n) \leq 2^{-n}$ for every $n$. A sequence $X$ is **captured** by the test if $X \in \bigcap_n \mathcal U_n$, and **passes** it otherwise. A sequence is **Martin-Löf random** if it passes every Martin-Löf test.
:::

The class $\bigcap_n \mathcal U_n$ captured by a test is a null $\Pi^0_2$ class, since its measure is at most $2^{-n}$ for every $n$. One may assume the test decreasing: the classes $\mathcal U_0 \cap \cdots \cap \mathcal U_n$ are uniformly $\Sigma^0_1$, decrease, satisfy the same bound, and have the same intersection. We write MLR for the class of Martin-Löf random sequences.

:::example{#ex-ml-tests}
1. A computable sequence $X$ is not random: $\mathcal U_n = [X \uh n]$ is a Martin-Löf test capturing $X$.
2. The covers of :ref{#ex-null-classes} are Martin-Löf tests. So a random sequence $X$ has $X(2i) \neq X(2i+1)$ for some $i$, and for every computable infinite set $A$, $X(a) = 1$ for some $a \in A$, hence for infinitely many, applying this to the tails of $A$.
:::

The bound $2^{-n}$ can be replaced by any computable bound tending to $0$.

:::lemma{#lem-test-bound}
Let $(\mathcal V_m)$ be uniformly $\Sigma^0_1$, and let $(q_m)$ be a computable sequence of rationals with $\lambda(\mathcal V_m) \leq q_m$ and $\lim_m q_m = 0$. Then no Martin-Löf random sequence belongs to $\bigcap_m \mathcal V_m$.
:::

:::proof{of=lem-test-bound}
For each $n$, let $m_n$ be the least $m$ with $q_m \leq 2^{-n}$; it exists since $q_m$ tends to $0$, and is computable from $n$. The sequence $\mathcal U_n = \mathcal V_{m_n}$ is uniformly $\Sigma^0_1$, with $\lambda(\mathcal U_n) \leq 2^{-n}$, and $\bigcap_m \mathcal V_m \subseteq \bigcap_n \mathcal U_n$.
:::

## A universal test

:::theorem[Martin-Löf]{#thm-universal-test}
There is a Martin-Löf test $(\mathcal U_n)$ such that $\bigcap_n \mathcal U_n$ contains every class captured by a Martin-Löf test. So a sequence is Martin-Löf random if and only if it passes $(\mathcal U_n)$.
:::

:::proof{of=thm-universal-test}
Let $(W_e)$ be the standard enumeration of the c.e. subsets of $\nat \times \bstr$. Every Martin-Löf test is of the form $([W_e^{[n]}]^{\prec})_n$ for some $e$, but most indices $e$ do not define tests. We transform each $W_e$ into a test, without changing those that already are.

Fix $e$ and $n$, and let $\sigma_0, \sigma_1, \dots$ be the elements of $W_e^{[n]}$ in the order of their enumeration (the list may be finite). Define finite sets $F_0 = \emptyset$, and $F_{i+1} = F_i \cup \{ \sigma_i \}$ if $\lambda([F_i \cup \{ \sigma_i \}]^{\prec}) \leq 2^{-n}$, and $F_{i+1} = F_i$ otherwise. The measure of the open class generated by a finite set of strings is a rational computable from the set, so the sets $F_i$ are computable from $e$, $n$ and $i$. Let $\mathcal V^e_n = \bigcup_i [F_i]^{\prec}$. Then:

- $(\mathcal V^e_n)_n$ is uniformly $\Sigma^0_1$, uniformly in $e$;
- $\lambda(\mathcal V^e_n) \leq 2^{-n}$, as the supremum of the measures of the increasing classes $[F_i]^{\prec}$, each at most $2^{-n}$;
- if $\lambda([W_e^{[n]}]^{\prec}) \leq 2^{-n}$, then every $\sigma_i$ is accepted, since $[F_i \cup \{ \sigma_i \}]^{\prec} \subseteq [W_e^{[n]}]^{\prec}$; so $\mathcal V^e_n = [W_e^{[n]}]^{\prec}$.

So $(\mathcal V^e_n)_n$ is a Martin-Löf test for every $e$, and every Martin-Löf test is one of them. Let
$$
\mathcal U_n = \bigcup_e \mathcal V^e_{n + e + 1}.
$$
It is uniformly $\Sigma^0_1$, and $\lambda(\mathcal U_n) \leq \sum_e 2^{-n-e-1} = 2^{-n}$. If $X$ is captured by the test $(\mathcal V^e_m)_m$, then $X \in \mathcal V^e_{n+e+1} \subseteq \mathcal U_n$ for every $n$.
:::

:::quiz[the universal test]
In the proof of :ref{#thm-universal-test}, why is each $W_e$ trimmed into $(\mathcal V^e_n)$ before taking the union?

- [x] Because most c.e. sets do not define tests, and their classes may have large measure; trimming bounds every $\mathcal V^e_n$ by $2^{-n}$ while leaving genuine tests unchanged.
- [ ] Because the set of indices $e$ of Martin-Löf tests is c.e., and the trimming enumerates it.

  The trimming never decides whether $e$ defines a test; this set of indices is not c.e. Trimming makes every index define a test.
- [ ] Because $\bigcup_e [W_e^{[n]}]^{\prec}$ is not uniformly $\Sigma^0_1$.

  It is uniformly $\Sigma^0_1$; the problem is its measure, which is $1$ since some $W_e$ contains the empty string.

---

Why is the component $\mathcal V^e_{n+e+1}$, rather than $\mathcal V^e_n$, used in $\mathcal U_n$?

- [x] To make the measures summable: the $e$-th test contributes at most $2^{-n-e-1}$, and the total is at most $2^{-n}$.
- [ ] To make the classes decreasing.

  The tests need not be decreasing; the shift is for the measure bound.
- [ ] Because $\mathcal V^e_n$ is not defined for $n < e$.

  It is defined for every $n$ and $e$.
:::

## Consequences

:::corollary{#cor-mlr-structure}
Let $(\mathcal U_n)$ be a universal Martin-Löf test.

1. The class MLR is conull.
2. For every $n$, the complement $\mathcal P_n = \cs \setminus \mathcal U_n$ is a $\Pi^0_1$ class of measure at least $1 - 2^{-n}$ consisting of random sequences. So MLR $= \bigcup_n \mathcal P_n$ is a $\Sigma^0_2$ class.
3. There is a low Martin-Löf random sequence, and a computably dominated one.
:::

:::proof{of=cor-mlr-structure}
1. The complement of MLR is $\bigcap_n \mathcal U_n$, which is null.
2. The complement of a $\Sigma^0_1$ class is a $\Pi^0_1$ class (:ref{#prop-pi01-equivalent}). A sequence outside $\mathcal U_n$ is outside $\bigcap_m \mathcal U_m$, hence random by universality. A sequence is random if and only if it is outside $\bigcap_n \mathcal U_n$, that is, in some $\mathcal P_n$.
3. $\mathcal P_1$ is a non-empty $\Pi^0_1$ class, since its measure is at least $1/2$. Apply the low basis theorem (:ref{#thm-low-basis}) and the computably dominated basis theorem (:ref{#thm-dominated-basis}).
:::

The two random sequences of (3) are very different. A computably dominated sequence that is not computable is not $\Delta^0_2$ (:ref{#def-computably-dominated}), whereas a low sequence is $\Delta^0_2$. The next lesson shows that Chaitin's $\Omega$ is random, giving a random sequence of the degree of $\emptyset'$.

## The law of large numbers

A random sequence should contain asymptotically as many zeros as ones. This is the law of large numbers, and it follows from a bound on the number of strings with a deviating frequency of ones.

:::fact[Hoeffding's inequality]{#fact-hoeffding}
For every $\varepsilon > 0$ and $m \geq 1$, the number of strings $\sigma$ of length $m$ with
$$
\left| \frac{|\{ i < m : \sigma(i) = 1 \}|}{m} - \frac{1}{2} \right| > \varepsilon
$$
is at most $2^{m+1} e^{-2 m \varepsilon^2}$.
:::

This is a classical estimate of probability theory, admitted here: it is the case of fair coin tosses of the inequality of Hoeffding (1963), and also follows from the Chernoff bound. A weaker bound, sufficient for the argument below, can be obtained from Chebyshev's inequality on the fourth moment.

:::proposition{#prop-large-numbers}
If $X$ is Martin-Löf random, then $\lim_{m} \frac{1}{m} |\{ i < m : X(i) = 1 \}| = \frac{1}{2}$.
:::

:::proof{of=prop-large-numbers}
Fix a rational $\varepsilon > 0$, let $C_m$ be the computable set of strings of length $m$ described in :ref{#fact-hoeffding}, and let $\mathcal V_n = \bigcup_{m \geq n} [C_m]^{\prec}$, a uniformly $\Sigma^0_1$ sequence. Let $a = e^{-2\varepsilon^2} < 1$. By subadditivity,
$$
\lambda(\mathcal V_n) \leq \sum_{m \geq n} 2^{-m} \cdot 2^{m+1} a^m = \frac{2 a^n}{1 - a}.
$$
One computes rationals $q_n$ with $2a^n / (1 - a) \leq q_n \leq 2a^n / (1-a) + 2^{-n}$; they tend to $0$. If the frequency of ones in $X \uh m$ differs from $\frac12$ by more than $\varepsilon$ for infinitely many $m$, then $X \in \mathcal V_n$ for every $n$, and $X$ is not random by :ref{#lem-test-bound}. A random $X$ therefore has frequencies eventually within $\varepsilon$ of $\frac12$, for every rational $\varepsilon > 0$.
:::

The same argument applies to blocks: for a random $X$ and a string $\tau$ of length $k$, the frequency of the occurrences of $\tau$ among the blocks $X(ik) \cdots X(ik + k - 1)$ tends to $2^{-k}$. Random sequences are **normal** in base $2^k$ for every $k$.

## Solovay tests

The rate $2^{-n}$ in the definition of tests is convenient for building a universal test, but proving that a given sequence is not random is often easier with a summability condition.

:::definition[Solovay]{#def-solovay-test}
A **Solovay test** is a uniformly $\Sigma^0_1$ sequence $(\mathcal S_n)$ with $\sum_n \lambda(\mathcal S_n) < \infty$. A sequence $X$ is **captured** by the test if $X \in \mathcal S_n$ for infinitely many $n$.
:::

By the Borel–Cantelli lemma, the class captured by a Solovay test is null. A Martin-Löf test is a Solovay test, with $\sum_n 2^{-n} = 2$, and a sequence in all its components is in infinitely many. The converse requires an argument.

:::theorem[Solovay]{#thm-solovay}
A sequence is Martin-Löf random if and only if it is not captured by any Solovay test.
:::

:::proof{of=thm-solovay}
($\Leftarrow$) A Martin-Löf test is a Solovay test, and a sequence captured by it as a Martin-Löf test is captured by it as a Solovay test.

($\Rightarrow$) Let $(\mathcal S_n)$ be a Solovay test, and let $d$ be such that $\sum_n \lambda(\mathcal S_n) \leq 2^d$. Let $\mathcal V_k$ be the class of sequences that belong to $\mathcal S_n$ for at least $2^k$ values of $n$. A sequence captured by the Solovay test belongs to every $\mathcal V_k$. We show that $(\mathcal V_{k + d})_k$ is a Martin-Löf test.

Fix an enumeration of the c.e. set defining $(\mathcal S_n)$. For a stage $s$, let $\mathcal S_{n,s}$ be the clopen class generated by the strings enumerated into the $n$-th component by stage $s$, for $n \leq s$, and $\mathcal S_{n,s} = \emptyset$ for $n > s$. Replacing a string $\sigma$ enumerated at stage $s$ by its extensions of length $t = \max(|\sigma|, s)$, enumerated at stage $t$, does not change the classes; so we may assume that the strings enumerated by stage $s$ have length at most $s$. Each $\mathcal S_{n,s}$ is then a union of cylinders $[\tau]$ with $|\tau| = s$. Let $D_s$ be the set of strings $\tau$ of length $s$ such that $[\tau] \subseteq \mathcal S_{n,s}$ for at least $2^k$ values of $n$; it is computable from $s$ and $k$. Counting pairs $(\tau, n)$ with $|\tau| = s$ and $[\tau] \subseteq \mathcal S_{n,s}$ in two ways gives
$$
2^k\, |D_s| \leq \sum_{|\tau| = s} |\{ n : [\tau] \subseteq \mathcal S_{n,s} \}| = \sum_{n \leq s} 2^s \lambda(\mathcal S_{n,s}) \leq 2^s \cdot 2^d,
$$
so $\lambda([D_s]^{\prec}) \leq 2^{d - k}$. The classes $[D_s]^{\prec}$ increase with $s$, since the classes $\mathcal S_{n,s}$ do. If $X$ belongs to $2^k$ classes $\mathcal S_n$, all these memberships are witnessed at some stage $s$, and then $X \uh s \in D_s$. So $\mathcal V_k = \bigcup_s [D_s]^{\prec}$: it is uniformly $\Sigma^0_1$, and $\lambda(\mathcal V_k) \leq 2^{d-k}$ by continuity. Hence $(\mathcal V_{k+d})_k$ is a Martin-Löf test, and it captures every sequence captured by $(\mathcal S_n)$.
:::

The counting step is Markov's inequality: the average number of classes $\mathcal S_n$ containing a sequence is $\sum_n \lambda(\mathcal S_n)$, so the sequences belonging to $2^k$ of them have measure at most $2^{-k}$ times this sum.

:::quiz[Solovay tests]
In the proof of :ref{#thm-solovay}, why is the constant $d$ not required to be computable from the test?

- [x] Because $d$ is a single number: for a fixed $d$, the sequence $(\mathcal V_{k+d})_k$ is uniformly $\Sigma^0_1$, and its existence is all that is needed.
- [ ] Because the sum $\sum_n \lambda(\mathcal S_n)$ is computable.

  The sum is only left-c.e. in general; the argument does not need its value.
- [ ] Because $d$ is always $0$.

  The sum of the measures may exceed $1$; $d$ compensates for it.

---

Why are the clopen approximations $\mathcal S_{n,s}$ used, rather than the classes $\mathcal S_n$ directly?

- [x] To reduce the measure estimate to a finite count over the strings of length $s$, and to obtain $\mathcal V_k$ as an effective union of clopen classes.
- [ ] Because the classes $\mathcal S_n$ are not measurable.

  Open classes are Borel, hence measurable.
- [ ] To make the classes $\mathcal S_n$ pairwise disjoint.

  They overlap in general; the count handles the overlaps.
:::

## Exercises

::::exercise{difficulty=1}
Let $X$ be Martin-Löf random. Show that for every $k$, some block $X(ik) \cdots X(ik + k - 1)$ consists of zeros only. Deduce that $X$ contains arbitrarily long runs of zeros.

:::solution
Fix $k$, and let $\mathcal V_N$ be the clopen class of sequences none of whose first $N$ blocks of length $k$ is $0^k$. The blocks are independent: $\lambda(\mathcal V_N) = (1 - 2^{-k})^N$, which tends to $0$ and is a computable rational. The sequence $(\mathcal V_N)_N$ is uniformly $\Sigma^0_1$, so by :ref{#lem-test-bound} a random sequence is outside some $\mathcal V_N$: one of its first $N$ blocks is $0^k$.
:::
::::

::::exercise{difficulty=1}
Let $X$ be Martin-Löf random. Show that $\sigma X$ is random for every string $\sigma$, and that the tail $Y = X(1) X(2) \cdots$ is random.

:::solution
For an open class $\mathcal U = [W]^{\prec}$ and a string $\sigma$, write $\mathcal U_\sigma = \{ Z : \sigma Z \in \mathcal U \}$. If some prefix of $\sigma$ is in $W$, then $\mathcal U_\sigma = \cs$ and $[\sigma] \subseteq \mathcal U$; otherwise $\mathcal U_\sigma = [\{ \tau : \sigma\tau \in W \}]^{\prec}$. In both cases $\mathcal U_\sigma$ is open, $\Sigma^0_1$ uniformly in an index of $\mathcal U$ and in $\sigma$ when $\mathcal U$ is $\Sigma^0_1$, and $\lambda(\mathcal U_\sigma) = 2^{|\sigma|} \lambda(\mathcal U \cap [\sigma])$, since $[\tau] \mapsto [\sigma\tau]$ divides measures by $2^{|\sigma|}$.

If $\sigma X$ is captured by $(\mathcal U_n)$, then $X$ belongs to every $(\mathcal U_n)_\sigma$, and $\lambda((\mathcal U_n)_\sigma) \leq 2^{|\sigma| - n}$; by :ref{#lem-test-bound}, $X$ is not random. For the tail, $X = iY$ with $i = X(0)$. If $Y$ is captured by $(\mathcal U_n)$, let $\mathcal V_n = \{ jZ : j \in \{0, 1\},\ Z \in \mathcal U_n \}$, a uniformly $\Sigma^0_1$ sequence with $\lambda(\mathcal V_n) = \lambda(\mathcal U_n)$; it captures $X$.
:::
::::

::::exercise{difficulty=2}
A sequence $G$ is **weakly 1-generic** if it meets every dense c.e. set of strings $W$: some prefix of $G$ belongs to $W$. A sequence is **Kurtz random** if it belongs to no null $\Pi^0_1$ class. Show that every Martin-Löf random sequence is Kurtz random, that every weakly 1-generic sequence is Kurtz random, and that no weakly 1-generic sequence is Martin-Löf random.

:::solution
A null $\Pi^0_1$ class $\mathcal P$ is covered by clopen classes $[F_n]^{\prec}$ of measure at most $2^{-n}$, computable from $n$ (second exercise of :ref{to="martin-lof-randomness/measure"}); this is a Martin-Löf test, so random sequences avoid $\mathcal P$.

Let $\mathcal P = [T]$ be null, with $T$ computable. The set $W$ of strings not in $T$ is computable. It is dense: if some $\sigma$ had all its extensions in $T$, then $[\sigma] \subseteq \mathcal P$ and $\lambda(\mathcal P) \geq 2^{-|\sigma|}$. A weakly 1-generic $G$ has a prefix outside $T$, so $G \notin \mathcal P$.

For each $n$, the set $D_n$ of strings $\tau$ of length at least $n$ with at least $\frac{2}{3}|\tau|$ ones is computable and dense: a string $\sigma$ is extended by $\sigma 1^k$ with $k = \max(2|\sigma|, n)$, which has at least $k \geq \frac{2}{3}(|\sigma| + k)$ ones. A weakly 1-generic $G$ meets every $D_n$, so the frequency of ones in $G \uh m$ is at least $\frac{2}{3}$ for infinitely many $m$. By :ref{#prop-large-numbers}, $G$ is not random.
:::
::::

## Notes and references

Martin-Löf (1966) introduced the tests and the universal test; the definition was meant to capture all effective statistical tests, the law of large numbers being the first example. Solovay's equivalent formulation appears in unpublished notes (1975). Kurtz (1981) introduced the randomness notion of the last exercise. The randomness of normal numbers goes back to Borel (1909).

- P. Martin-Löf, *The definition of random sequences*, Information and Control 9 (1966), 602–619.
- W. Hoeffding, *Probability inequalities for sums of bounded random variables*, Journal of the American Statistical Association 58 (1963), 13–30.
- S. A. Kurtz, *Randomness and genericity in the degrees of unsolvability*, PhD thesis, University of Illinois, 1981.
- R. G. Downey and D. R. Hirschfeldt, *Algorithmic Randomness and Complexity*, Springer, 2010.
