A closed class is the set of paths through a binary tree. When the tree is computable, the conditions defining the class can be checked by an algorithm on finite prefixes, and the class is a $\Pi^0_1$ class. This lesson gives the equivalent descriptions of $\Pi^0_1$ classes, by computable trees, co-c.e. trees, $\Sigma^0_1$ complements and functionals, and the main examples: separating sets of c.e. sets and $\{0, 1\}$-valued diagonally non-computable functions. It then shows that compactness is effective: the emptiness of a $\Pi^0_1$ class is a $\Sigma^0_1$ property of its index. The rest of the course studies how complex the members of non-empty $\Pi^0_1$ classes must be.

We use the notation of :ref{to="pi01-classes/cantor-space"}: $[\sigma]$ is the cylinder of the sequences extending $\sigma$, $[W]^{\prec}$ the open class generated by a set of strings $W$, $[T]$ the class of paths through a tree $T$, and $2^n$ the set of strings of length $n$.

## Definition and equivalent descriptions

:::definition{#def-pi01-class}
A class $\mathcal P \subseteq \cs$ is a **$\Pi^0_1$ class** if $\mathcal P = [T]$ for some computable binary tree $T$. A **$\Sigma^0_1$ class** is a class $[W]^{\prec}$ with $W$ a c.e. set of strings. An **index** of a $\Pi^0_1$ class is an index of the characteristic function of such a tree $T$.
:::

:::proposition{#prop-pi01-equivalent}
For $\mathcal P \subseteq \cs$, the following are equivalent:

1. $\mathcal P$ is a $\Pi^0_1$ class;
2. $\mathcal P = [T]$ for some co-c.e. tree $T$;
3. $\mathcal P = \{ X : \forall n\ R(X \uh n) \}$ for some computable relation $R$ on strings;
4. $\mathcal P = \{ X : \Phi^X_e(0)\diverge \}$ for some $e$;
5. the complement of $\mathcal P$ is a $\Sigma^0_1$ class.

Moreover, the passages between these descriptions are uniform in indices.
:::

:::proof{of=prop-pi01-equivalent}
(1 ⇒ 2) A computable tree is co-c.e.

(2 ⇒ 5) The complement of $[T]$ is $[\bstr \setminus T]^{\prec}$, and $\bstr \setminus T$ is c.e.

(5 ⇒ 4) If the complement is $[W]^{\prec}$ with $W$ c.e., let $\Phi_e$ be the functional which, with oracle $X$, enumerates $W$ and halts as soon as it finds a string $\sigma \in W$ with $\sigma \prec X$. Then $\Phi^X_e(0)\converge$ if and only if $X \in [W]^{\prec}$.

(4 ⇒ 3) Let $R(\sigma)$ be "$\Phi^\sigma_e(0)[|\sigma|]\diverge$". It is computable, and by :ref{#prop-oracle-stages}, $\Phi^X_e(0)\diverge$ if and only if $R(X \uh n)$ for every $n$.

(3 ⇒ 1) Let $T = \{ \sigma : \forall \tau \preceq \sigma\ R(\tau) \}$. It is a computable tree, and $X \in [T]$ if and only if $R(X \uh n)$ for every $n$.

All steps transform indices by computable functions.
:::

Every $\Pi^0_1$ class is closed, by :ref{#prop-closed-tree}, but the converse fails: there are uncountably many closed classes, for instance the singletons, and only countably many $\Pi^0_1$ classes, since each is given by an index. An explicit closed class that is not $\Pi^0_1$ is in the second quiz below. The tree of :ref{#prop-closed-tree}, whose nodes are all extendible, need not be computable when $\mathcal P$ is $\Pi^0_1$: by :ref{#prop-pi01-emptiness} below it is co-c.e., but if it were computable, the leftmost path, which always turns to an extendible node, would be computable, and the next lesson gives a non-empty $\Pi^0_1$ class without computable member.

:::example{#ex-pi01-classes}
1. Let $A$ and $B$ be disjoint c.e. sets. The class $\mathcal S(A, B) = \{ X : A \subseteq X \text{ and } X \cap B = \emptyset \}$ of **separating sets** is $\Pi^0_1$: $X \notin \mathcal S(A, B)$ if and only if some $n \in A$ has $X(n) = 0$ or some $n \in B$ has $X(n) = 1$, a $\Sigma^0_1$ condition on prefixes of $X$.
2. The class $\mathrm{DNC}_2 = \{ X : X(e) \neq \Phi_e(e) \text{ for every } e \text{ with } \Phi_e(e)\converge \}$ is $\Pi^0_1$, by the same argument; its elements are the **diagonally non-computable** $\{0, 1\}$-valued functions.
3. A singleton $\{ Y \}$ with $Y$ computable is a $\Pi^0_1$ class, with tree $\{ Y \uh n : n \in \nat \}$.
:::

## Effective compactness

The emptiness of a closed class is, a priori, a statement about all sequences. For a $\Pi^0_1$ class, compactness reduces it to a statement about the finitely many strings of one length, which an algorithm can check.

:::proposition{#prop-pi01-emptiness}
Given an index of a computable tree $T$, the property $[T] = \emptyset$ is $\Sigma^0_1$: $[T] = \emptyset$ if and only if $T$ has no node of some length $n$. Consequently, the set of $e$ such that $\{ X : \Phi^X_e(0)\diverge \} = \emptyset$ is c.e., and the extendible nodes of a computable tree form a co-c.e. set.
:::

:::proof{of=prop-pi01-emptiness}
By :ref{#lem-weak-konig}, $[T] = \emptyset$ if and only if $T$ is finite, if and only if some length $n$ has no node in $T$, since $T$ is closed under prefixes. For a given $n$, this is decided by testing the $2^n$ strings of length $n$. For the class $\{ X : \Phi^X_e(0)\diverge \}$, the tree $\{ \sigma : \forall \tau \preceq \sigma\ \Phi^\tau_e(0)[|\tau|]\diverge \}$ of :ref{#prop-pi01-equivalent} is computable, uniformly in $e$, so its emptiness is a $\Sigma^0_1$ property of $e$. (By contrast, the set of $e$ such that $\Phi_e$ is the characteristic function of a tree without paths is not c.e.: the set of indices of total functions reduces to it.) A node $\sigma$ is not extendible if and only if the computable tree $\{ \tau \in T : \tau \preceq \sigma \text{ or } \sigma \preceq \tau \}$ has no path, which is a $\Sigma^0_1$ condition, uniformly in $\sigma$.
:::

This is the **effective compactness** of Cantor space: emptiness of a $\Pi^0_1$ class, a priori a statement about all sequences $X$, is in fact $\Sigma^0_1$. Non-emptiness, which asks for an infinite path, is accordingly a $\Pi^0_1$ property: a finite amount of computation can show that a class is empty, never that it is non-empty.

:::quiz[Π⁰₁ classes]
Why is the emptiness of $[T]$, for a computable tree $T$, a $\Sigma^0_1$ property?

- [x] By weak König's lemma, $[T]$ is empty if and only if $T$ is finite, which is witnessed by a length $n$ at which $T$ has no node, a decidable condition for each $n$.
- [ ] Because $T$ is computable.

  Computability of $T$ makes each test decidable; the reduction from "no path" to "finite" is compactness.
- [ ] Because $[T]$ is a closed class.

  Closedness is needed for compactness, but the statement concerns the complexity of a property of indices.

---

Which of these classes are $\Pi^0_1$?

- [ ] $\{ X : X \subseteq \emptyset' \}$.

  The class is closed, but not $\Pi^0_1$: a string $0^n 1$ has a cylinder disjoint from the class if and only if $n \notin \emptyset'$, and by :ref{#ex-pi01-disjoint-cylinders} the set of such $n$, the complement of $\emptyset'$, would then be c.e.
- [x] $\{ X : X \cap \emptyset' = \emptyset \}$.

  $X \cap \emptyset' \neq \emptyset$ is the $\Sigma^0_1$ condition "some $n$ enters $\emptyset'$ with $X(n) = 1$".
- [ ] $\{ X : X \text{ is finite} \}$.

  It is not closed: the sequences $1^n 0 0 \cdots$ are finite sets converging to the infinite set $\nat$.
:::

## Exercises

::::exercise{difficulty=1 #ex-pi01-intersection-union}
Show that the intersection of two $\Pi^0_1$ classes, and the union of two $\Pi^0_1$ classes, are $\Pi^0_1$ classes, uniformly in indices.

:::solution
If $\mathcal P = [S]$ and $\mathcal Q = [T]$ with $S$ and $T$ computable trees, then $\mathcal P \cap \mathcal Q = [S \cap T]$ and $\mathcal P \cup \mathcal Q = [S \cup T]$. The first equality is immediate. For the second, a path of $S \cup T$ that is not a path of $S$ has a prefix $\sigma \notin S$; all its longer prefixes are then outside $S$, hence in $T$, and its shorter prefixes are prefixes of nodes of $T$, hence in $T$; so it is a path of $T$.
:::
::::

::::exercise{difficulty=2 #ex-pi01-disjoint-cylinders}
Show that a class $\mathcal P \subseteq \cs$ is $\Pi^0_1$ if and only if the set of strings $\sigma$ with $[\sigma] \cap \mathcal P = \emptyset$ is c.e., and $\mathcal P$ is closed.

:::solution
If $\mathcal P = [T]$ with $T$ computable, then $[\sigma] \cap \mathcal P = \emptyset$ is the $\Sigma^0_1$ property of :ref{#prop-pi01-emptiness}, uniformly in $\sigma$. Conversely, if $\mathcal P$ is closed and $W = \{ \sigma : [\sigma] \cap \mathcal P = \emptyset \}$ is c.e., then the complement of $\mathcal P$ is $[W]^{\prec}$: a sequence outside the closed class $\mathcal P$ has a cylinder neighborhood disjoint from $\mathcal P$. So the complement is a $\Sigma^0_1$ class, and $\mathcal P$ is $\Pi^0_1$ by :ref{#prop-pi01-equivalent}.
:::
::::

::::exercise{difficulty=2 #ex-nonempty-indices}
Show that there is a computable function $f$ such that, for every index $e$ of a computable tree $T_e$, $f(e)$ is the index of a computable tree $S_e$ with $[S_e] \neq \emptyset$, and $[S_e] = [T_e]$ whenever $[T_e] \neq \emptyset$. So the non-empty $\Pi^0_1$ classes can be listed by a computable sequence of indices, although the set of $e$ such that $\{ X : \Phi^X_e(0)\diverge \}$ is non-empty is not c.e.

:::solution
The idea is to follow $T_e$ as long as it has nodes at every length, and to freeze it on a single path if it dies out. Given $\sigma$, check whether $T_e$ has a node of every length $\ell \leq |\sigma|$. If so, put $\sigma \in S_e$ if and only if $\sigma \in T_e$. Otherwise, let $L < |\sigma|$ be the largest length such that $T_e$ has nodes of all lengths $\ell \leq L$, and $\rho$ the leftmost node of $T_e$ of length $L$; put $\sigma \in S_e$ if and only if $\sigma = \rho\, 0^{|\sigma| - L}$. This is decidable uniformly in $e$ and $\sigma$, so $f$ is computable by SMN. A prefix $\tau$ of a node $\sigma \in S_e$ is in $S_e$: if $|\tau| \leq L$ in the second case, then $\tau \preceq \rho \in T_e$ and the first case applies to $\tau$; otherwise the same case and the same $L$ apply to $\tau$ as to $\sigma$. If $T_e$ is infinite, the first case always applies, and $S_e = T_e$. If $T_e$ is finite, $[T_e] = \emptyset$, and $S_e$ has the path $\rho\, 0^\infty$. The set of $e$ such that $\{ X : \Phi^X_e(0)\diverge \}$ is non-empty is co-c.e. by :ref{#prop-pi01-emptiness}. It is not c.e.: by SMN there is a computable $g$ such that $\Phi^X_{g(n)}(0)$ ignores $X$ and converges if and only if $\Phi_n(n)\converge$, so that the class of index $g(n)$ is $\cs$ if $n \notin \emptyset'$ and empty otherwise; if the set were c.e., the complement of $\emptyset'$ would be c.e.
:::
::::

## Notes and references

$\Pi^0_1$ classes were studied from the early 1950s, notably by Kleene and Kreisel, in connection with the completeness theorem and intuitionistic analysis; Dean and Walsh describe this early history. The systematic theory of their members is due to Jockusch and Soare (1972). Cenzer and Remmel's survey gives a broad account.

Soare's *Turing Computability* proves the effective compactness theorem in Section 8.5 (:ref{#prop-pi01-emptiness} is part of his Theorem 8.5.1) and the separating sets example as Theorem 9.3.2. Downey and Hirschfeldt, Section 2.19.1, and Nies, Section 1.8, give the equivalent descriptions of $\Pi^0_1$ classes; Hirschfeldt's *Slicing the Truth*, Section 3.1, proves the emptiness criterion as Proposition 3.9. Monin and Patey's chapter on $\Pi^0_1$ classes follows the same order as this lesson and the previous one.
