Randomness relative to an oracle $X$ asks a sequence to pass all tests that $X$ can enumerate. The stronger the oracle, the more tests, and the fewer random sequences. Van Lambalgen's theorem describes how relative randomness interacts with the join: a sequence $A \oplus B$ is random if and only if $A$ is random and $B$ is random relative to $A$. The theorem has consequences for the Turing degrees of random sequences, and it characterizes randomness relative to $\emptyset'$, called 2-randomness, in terms of Chaitin's $\Omega$.

## Relative randomness

:::definition{#def-relative-ml}
Let $X$ be a set. A **Martin-Löf test relative to $X$** is a sequence of classes $(\mathcal U_n)$, uniformly $\Sigma^0_1(X)$, with $\lambda(\mathcal U_n) \leq 2^{-n}$. A sequence is **Martin-Löf random relative to $X$**, or **$X$-random**, if it passes every such test. The class of $X$-random sequences is written $\mathrm{MLR}^X$. For $n \geq 1$, a sequence is **$n$-random** if it is random relative to $\emptyset^{(n-1)}$; the 1-random sequences are the Martin-Löf random ones.
:::

A class is $\Sigma^0_1(X)$ if it is generated by a set of strings c.e. in $X$; uniformity means that the $n$-th set is enumerated by a fixed oracle machine with input $n$. All results of the course on Martin-Löf randomness relativize, with the same proofs: there is a universal test relative to $X$, $\mathrm{MLR}^X$ is conull, Solovay tests relative to $X$ define the same notion, and $Z \in \mathrm{MLR}^X$ if and only if $K^X(Z \uh n) \geq n - O(1)$, where $K^X$ is prefix-free complexity relative to $X$. If $Y \leq_T X$, every test relative to $Y$ is a test relative to $X$, so $\mathrm{MLR}^X \subseteq \mathrm{MLR}^Y$.

:::example{#ex-relative-random}
1. If $X$ is computable, the tests relative to $X$ are the Martin-Löf tests, and $\mathrm{MLR}^X = \mathrm{MLR}$.
2. If $Z \leq_T X$, then $Z$ is not $X$-random: the classes $[Z \uh n]$ are uniformly $\Sigma^0_1(X)$, of measure $2^{-n}$, and contain $Z$. In particular no sequence is random relative to itself, and Chaitin's $\Omega$, which is random (:ref{#cor-omega-random}) and computable in $\emptyset'$ (:ref{#thm-omega}), is not 2-random. So the inclusion of the 2-random sequences in the random ones is strict.
3. Relativizing the existence of a low random sequence (:ref{#cor-mlr-structure} (3)) to $\emptyset'$ gives a 2-random sequence $Z$ with $(Z \oplus \emptyset')' \leq_T \emptyset''$; in particular $Z \leq_T \emptyset''$. The same argument shows that the inclusions $\mathrm{MLR}^{\emptyset^{(n)}} \subseteq \mathrm{MLR}^{\emptyset^{(n-1)}}$ are all strict.
:::

Two facts of measure theory are used below. They concern a class $\mathcal W \subseteq \cs$ seen as a class of pairs, through the identification of $X \oplus Y$ with $(X, Y)$, and its sections $\mathcal W_X = \{ Y : X \oplus Y \in \mathcal W \}$.

:::fact[Fubini]{#fact-fubini}
For every open class $\mathcal W$, the function $X \mapsto \lambda(\mathcal W_X)$ is measurable and $\lambda(\mathcal W) = \int \lambda(\mathcal W_X)\, dX$. In particular, for every $q > 0$, $\lambda(\{ X : \lambda(\mathcal W_X) > q \}) \leq \lambda(\mathcal W) / q$.
:::

This is Fubini's theorem for the product of two copies of the uniform measure, which is the uniform measure under the identification; the second statement is Markov's inequality. Both are admitted. Note that if $\mathcal W$ is $\Sigma^0_1$, then $\mathcal W_X$ is $\Sigma^0_1(X)$ uniformly in $X$, and $\{ X : \lambda(\mathcal W_X) > q \}$ is $\Sigma^0_1$, uniformly in a rational $q$, since $\lambda(\mathcal W_X)$ is left-c.e. relative to $X$, uniformly.

## Van Lambalgen's theorem

The proof translates between tests for pairs and tests relative to an oracle, and :ref{#fig-sections} contains both translations. A family of tests relative to every oracle $X$, given by one oracle machine, is gathered into a single class of pairs; its measure is the average of the measures of the sections, by Fubini's theorem, so it is small when every section is small. Conversely, a class of pairs of small measure gives, for each oracle $X$, its section. The section is not small for every $X$, so it is not a test relative to every oracle; but the oracles for which it is too large form a class of small measure, by Markov's inequality, and a random oracle avoids almost all of these classes.

Every oracle-dependent sequence of classes can be trimmed into a test for every oracle, as in the construction of the universal test (:ref{#thm-universal-test}): from an oracle machine enumerating $\mathcal V^X_n$, one computes another enumerating $\widehat{\mathcal V}^X_n \subseteq \mathcal V^X_n$, with $\lambda(\widehat{\mathcal V}^X_n) \leq 2^{-n}$ for every $X$, and $\widehat{\mathcal V}^X_n = \mathcal V^X_n$ whenever $\lambda(\mathcal V^X_n) \leq 2^{-n}$.

:::theorem[van Lambalgen]{#thm-van-lambalgen}
For all sets $A$ and $B$, $A \oplus B$ is Martin-Löf random if and only if $A$ is Martin-Löf random and $B$ is Martin-Löf random relative to $A$.
:::

:::proof{of=thm-van-lambalgen}
We prove both directions by contraposition.

($\Rightarrow$) Suppose $A$ is captured by a test $(\mathcal U_n)$. Then $A \oplus B$ belongs to the classes $\{ X \oplus Y : X \in \mathcal U_n \}$, which are uniformly $\Sigma^0_1$ with the same measures; so $A \oplus B$ is not random. Suppose $B$ is captured by a test relative to $A$; by trimming, we may assume it is given by an oracle machine $X \mapsto (\mathcal V^X_n)$ with $\lambda(\mathcal V^X_n) \leq 2^{-n}$ for every $X$. Let $\mathcal W_n = \{ X \oplus Y : Y \in \mathcal V^X_n \}$, uniformly $\Sigma^0_1$. By :ref{#fact-fubini}, $\lambda(\mathcal W_n) = \int \lambda(\mathcal V^X_n)\, dX \leq 2^{-n}$, and $A \oplus B \in \bigcap_n \mathcal W_n$.

($\Leftarrow$) Suppose $A \oplus B \in \bigcap_n \mathcal U_n$ for a Martin-Löf test $(\mathcal U_n)$, and $A$ random. For each $n$, let $\mathcal V^X_n = (\mathcal U_{2n})_X = \{ Y : X \oplus Y \in \mathcal U_{2n} \}$, and $\mathcal S_n = \{ X : \lambda(\mathcal V^X_n) > 2^{-n} \}$. The classes $\mathcal S_n$ are uniformly $\Sigma^0_1$, and $\lambda(\mathcal S_n) \leq 2^{-2n} / 2^{-n} = 2^{-n}$ by :ref{#fact-fubini}. So $(\mathcal S_n)$ is a Solovay test, and since $A$ is random, $A \notin \mathcal S_n$ for all $n \geq N$, for some $N$ (:ref{#thm-solovay}). For $n \geq N$, $\lambda(\mathcal V^A_n) \leq 2^{-n}$, so $(\mathcal V^A_{n+N})_n$ is a Martin-Löf test relative to $A$. It captures $B$, since $A \oplus B \in \mathcal U_{2n}$ for every $n$. So $B$ is not random relative to $A$.
:::

The two directions use the two techniques of effective measure theory met in the course on Martin-Löf randomness: **averaging**, through Fubini's theorem, to merge a uniform family of relative tests into one test; and a **Solovay test** to discard the bad oracles, a step that needs the hypothesis that $A$ is random.

The statement of the theorem is not symmetric in $A$ and $B$, but its consequences are: $A \oplus B$ is random if and only if $B \oplus A$ is (second exercise below), so $A$ is random and $B$ is $A$-random if and only if $B$ is random and $A$ is $B$-random. Two sequences $A$ and $B$ with this property, that is, such that $A \oplus B$ is random, are called **mutually random**.

:::quiz[van Lambalgen's theorem]
In the direction ($\Leftarrow$) of :ref{#thm-van-lambalgen}, why is the randomness of $A$ needed?

- [x] To exclude the oracles $X$ for which the sections $\mathcal V^X_n$ are too large: these oracles form a Solovay test, which $A$ passes, so for large $n$ the sections at $A$ have the measure required by a test.
- [ ] To make the classes $\mathcal V^A_n$ uniformly $\Sigma^0_1(A)$.

  They are uniformly $\Sigma^0_1(A)$ for every $A$; the issue is their measure.
- [ ] To show that $B$ is random.

  The conclusion is that $B$ is not random relative to $A$; the randomness of $A$ is a hypothesis of the contrapositive.

---

Why is $\mathcal U_{2n}$ used to define $\mathcal V^X_n$, rather than $\mathcal U_n$?

- [x] So that Markov's inequality gives $\lambda(\mathcal S_n) \leq 2^{-2n} / 2^{-n} = 2^{-n}$, a summable bound; with $\mathcal U_n$, the bound would be $1$.
- [ ] Because $\mathcal U_n$ might not contain $A \oplus B$.

  $A \oplus B$ belongs to every component.
- [ ] To make the test decreasing.

  Monotonicity is not used.
:::

The proof relativizes to any oracle $Z$: $A \oplus B$ is $Z$-random if and only if $A$ is $Z$-random and $B$ is $(A \oplus Z)$-random. For $Z = \emptyset^{(n-1)}$, this is van Lambalgen's theorem for $n$-randomness, where "$B$ is $n$-random relative to $A$" means random relative to $A \oplus \emptyset^{(n-1)}$.

The theorem is special to Martin-Löf randomness and its relativizations. For Schnorr randomness and computable randomness, defined in the course on martingales, the direction ($\Leftarrow$) holds with the same proof, but the direction ($\Rightarrow$) fails: Merkle, Miller, Nies, Reimann and Stephan (2006) found sequences $A$ and $B$ such that $A \oplus B$ is Schnorr random while $B$ is not Schnorr random relative to $A$ (Downey–Hirschfeldt, Theorem 7.1.13 and Corollary 8.11.15). With an oracle, the measures of a Schnorr test need only be computable in the oracle; Miyabe and Rute (2013) showed that the theorem holds for Schnorr randomness when the measures are computed by a single machine for all oracles.

:::corollary{#cor-van-lambalgen}
1. If $A \oplus B$ is random, then $A$ and $B$ are Turing incomparable.
2. A sequence $A$ is 2-random if and only if $A \oplus \Omega$ is random, where $\Omega$ is Chaitin's halting probability. In particular, no 2-random sequence computes $\emptyset'$.
:::

:::proof{of=cor-van-lambalgen}
1. If $B \leq_T A$, then $B$ is not random relative to $A$, by :ref{#ex-relative-random} (2). By the theorem, $A \oplus B$ is not random. If $A \leq_T B$, apply the same argument to $B \oplus A$, which is random as the image of $A \oplus B$ under the computable measure-preserving map exchanging even and odd positions.
2. Since $\Omega \equiv_T \emptyset'$ (:ref{#thm-omega}), randomness relative to $\Omega$ is randomness relative to $\emptyset'$. By the theorem applied to $\Omega \oplus A$, this sequence is random if and only if $A$ is random relative to $\Omega$, since $\Omega$ is random (:ref{#cor-omega-random}); and $\Omega \oplus A$ is random if and only if $A \oplus \Omega$ is. If a 2-random $A$ computed $\emptyset'$, then $A \geq_T \Omega$, contradicting (1) for the random sequence $A \oplus \Omega$.
:::

Item (1) says that the two halves of a random sequence are Turing incomparable, so that $A$ and $B$ are both strictly below $A \oplus B$: a random sequence never has minimal degree, a result of Kurtz (Downey–Hirschfeldt, Corollary 6.9.5). Item (2) replaces an oracle by a single random sequence: 2-randomness is mutual randomness with $\Omega$.

:::quiz[the corollary]
In the proof of :ref{#cor-van-lambalgen} (2), why does a 2-random $A$ that computes $\emptyset'$ lead to a contradiction?

- [x] It would compute $\Omega$, while $A \oplus \Omega$ is random by the first statement of (2), and the halves of a random sequence are Turing incomparable by (1).
- [ ] Because $\emptyset'$ is not random.

  Computing a non-random set is no obstacle: every sequence computes the computable sets, and $\Omega$ computes $\emptyset'$.
- [ ] Because 2-random sequences are not $\Delta^0_2$.

  They are not, by :ref{#ex-relative-random} (2), but a sequence that computes $\emptyset'$ need not be $\Delta^0_2$.
:::

## 2-randomness

The 2-random sequences avoid every class captured by a Martin-Löf test relative to $\emptyset'$. They are computationally weaker than arbitrary random sequences: by :ref{#cor-van-lambalgen} (2), a 2-random sequence does not compute $\emptyset'$, whereas $\Omega$ is random and computes it. Two further results, admitted here, show that 2-random sequences behave like generic ones. Every 2-random sequence has hyperimmune degree: this is due to Kurtz (1981), who proved more, that a 2-random sequence is c.e. relative to a set strictly below it, and was proved by Kautz (1991) by another method (Nies, Corollary 3.6.15; Downey–Hirschfeldt, Theorem 8.21.2). And every 2-random sequence $A$ is **generalized low**, $A' \equiv_T A \oplus \emptyset'$ (Kautz 1991; Downey–Hirschfeldt, Theorem 8.14.1). Neither property holds for all random sequences: there are computably dominated random sequences (:ref{#cor-mlr-structure} (3)), and $\Omega' \equiv_T \emptyset''$ is not computable in $\Omega \oplus \emptyset' \equiv_T \emptyset'$.

2-randomness has a characterization by plain complexity: $A$ is 2-random if and only if $C(A \uh n) \geq n - O(1)$ for infinitely many $n$. Nies, Stephan and Terwijn (2005) proved both directions; Miller (2004) had independently proved that every 2-random sequence satisfies this condition (Downey–Hirschfeldt, Theorems 6.11.3 and 6.11.6; Nies, Theorem 3.6.10). For prefix-free complexity, the Levin–Schnorr theorem relativized to $\emptyset'$ characterizes 2-randomness by $K^{\emptyset'}(A \uh n) \geq n - O(1)$; the theorem of Miller and Nies–Stephan–Terwijn removes the oracle at the price of an infinitely-often condition.

The next lesson studies a notion strictly between 2-randomness and Martin-Löf randomness, obtained by keeping the tests of complexity $\Pi^0_2$ but dropping the bound on their measures.

## Exercises

::::exercise{difficulty=1}
Let $Z$ be random, $Z_0 = \{ n : 2n \in Z \}$ and $Z_1 = \{ n : 2n + 1 \in Z \}$. Show that $Z_0$ and $Z_1$ are random, and Turing incomparable.

:::solution
$Z = Z_0 \oplus Z_1$. By :ref{#thm-van-lambalgen}, $Z_0$ is random and $Z_1$ is random relative to $Z_0$, hence random. By :ref{#cor-van-lambalgen} (1), they are Turing incomparable.
:::
::::

::::exercise{difficulty=1}
Show that if $A$ is random and $B$ is random relative to $A$, then $B$ is random and $A$ is random relative to $B$.

:::solution
By :ref{#thm-van-lambalgen}, $A \oplus B$ is random. The map $X \oplus Y \mapsto Y \oplus X$ is computable and preserves the measure, so it maps Martin-Löf tests to Martin-Löf tests; hence $B \oplus A$ is random. By :ref{#thm-van-lambalgen} again, $B$ is random and $A$ is random relative to $B$.
:::
::::

::::exercise{difficulty=1}
Show that if $A$ is 2-random, then $\Omega$ is random relative to $A$. Deduce that $\Omega$ is random relative to almost every sequence.

:::solution
By :ref{#cor-van-lambalgen} (2), $A \oplus \Omega$ is random; by the previous exercise, $\Omega$ is random relative to $A$. The class of 2-random sequences is conull, since it is the class $\mathrm{MLR}^{\emptyset'}$, so $\Omega$ is random relative to almost every sequence. The same argument applies to every random sequence $B$ in place of $\Omega$, with "random relative to $B$" in place of "2-random".
:::
::::

## Notes and references

Van Lambalgen proved his theorem in his thesis (1987). The proofs given here use Fubini's theorem in both directions; Downey and Hirschfeldt prove ($\Rightarrow$) with a universal oracle test and a Solovay test (Theorem 6.9.1), and ($\Leftarrow$) by an argument due to Nies (Theorem 6.9.2). Kurtz's thesis (1981) and Kautz's thesis (1991) contain the basic results on $n$-randomness. Downey and Hirschfeldt treat relative randomness and van Lambalgen's theorem in Sections 6.8–6.9, its failure for weaker notions in Sections 7.1.2 and 8.11.3, 2-randomness and plain complexity in Section 6.11; Nies treats 2-randomness in Section 3.6.
